### Clip-Specific Scaling Settings

A further group of Scaling and Resize Filter settings lives in the Video Inspector for whichever clips are selected, offering the very same choices as the Project Settings window does, the difference being that these apply only to one particular clip. They come in handy whenever the project-wide scaling setting suits the bulk of your clips yet a few individual clips would do better with their own dedicated values.

### Edit Sizing in the Cut and Edit pages

Inside the Video Inspector sits a group of Transform parameters you can use to reshape clips in the Timeline. They function on their own, apart from the Input Sizing controls over on the Color page. Having dedicated Edit sizing controls fulfills several distinct purposes:

- They suit editors well and animate readily for producing motion graphics effects directly on the Cut and Edit page timelines. On top of that, they isolate editor transform changes from colorist transform changes, giving a tidy split of roles and accountability.
- Edit sizing parameters additionally hold incoming transform data brought in from imported AAF and XML projects originating in other applications, so the imported transforms stay apart from whatever colorists and finishing artists adjust.

The Transform parameters in the Inspector of the Edit page

When you import an AAF or XML project file and switched on the “Use sizing information” checkbox, any clip carrying position, scale, rotation, or crop settings from the source NLE will have those tweaks land on these transform parameters, which conveniently isolates the imported transform settings from the other DaVinci Resolve-native transform settings. Beyond that, the Video Inspector also holds a group of Dynamic Zoom parameters letting you build fast animated transforms through graphical controls tied to the opening and closing states of an animated transform. These transforms, though, get grouped together with the rest of the Edit page Transform parameters when it comes to the sequence of sizing operations running across DaVinci Resolve.

### Image Stabilization

Within the Cut, Edit, and Color pages, DaVinci Resolve offers Image Stabilization controls that all drive the very same transform step, the one occurring between Edit sizing and Input Sizing along the image processing pipeline. The transform produced through the Image Stabilization controls reaches all the way back to either each clip's source resolution or, when the Fusion page is in use, the resolution that page outputs.

### Input Sizing on the Color Page

Over on the Color page, the Sizing palette holds yet another dedicated group of keyframable transform parameters that pair with the assorted DaVinci control panels, enabling the colorist to make pan and scan changes as a project moves along. These parameters run independently of the Edit page Transform parameters, which lets you keep imported transform settings apart from whatever other transform settings you apply. Still, as a convenience the Edit sizing controls show up on the Color page too. A transform produced through the Input Sizing controls reaches all the way back to either each clip's source resolution or, with the Fusion page active, the resolution that page outputs.

### Node Sizing on the Color Page

Node Sizing lets you make individual sizing changes to clips one node at a time within the Color page, an idea akin to working with Transform nodes over on the Fusion page. Every Node Sizing change inside a grade stacks cumulatively, and whatever keyframing you do to Node Sizing parameters is held in that node's Node Format keyframe track within the Keyframe Editor. A couple of solid Node Sizing examples are re-aligning color channels one by one alongside the Splitter/Combiner nodes, or copying windowed regions of an image by shifting them around the frame. Later Node Sizing operations don't trace back to a clip's source resolution, so chaining several Node Sizing operations to shrink then grow an image will cost you image resolution and sharpness.

### Output Sizing on the Color Page

Output sizing is one more transform, applied once Edit sizing, Fusion sizing, Input sizing, and Node sizing have all run. It acts as a blanket change touching every clip simultaneously, which makes it ideal for last-minute format tweaks meant to reach the whole program. Strictly speaking, Output Sizing takes in the Blanking controls, though those warrant their own separate treatment. Output Sizing likewise won't trace back to a clip's source resolution, so if Edit or Input Sizing shrinks a clip and Output Sizing then enlarges it once more, the end result comes out a touch softer because you're enlarging the lower-resolution image that Input Sizing produced.

### Output Blanking

Output blanking isn't itself a sizing operation, yet it's so frequently connected that it belongs here. Blanking is a tweak that places black regions along the top, bottom, left, or right edge of an image, producing “letterboxing” (black bars across the top and bottom of the image) or “pillarboxing” (black bars down the left and right of the image) to occupy the empty parts of an image frame that runs shorter or thinner than the current output resolution. After the DaVinci Resolve image processing pipeline has run every transform, compositing operation, and color correction, the final step carried out is Output blanking, provided it's switched on. That ensures overlapping images, grading, and other tweaks stay correctly “blacked out” regardless of what you're doing to the program. You'll find the Output Blanking controls in the Timeline menu (offered as a list of aspect ratios) and also among the Output Sizing parameters within the Color page Sizing palette (through the Top, Right, Bottom, and Left controls). TIP: When the Data Burn-In window is enabled, the text and graphics it overlays are the sole effects rendered ahead of any picture areas that blanking touches. That lets you place timecode and similar information across letterboxed regions without covering the picture you want kept clear.

### Format Resolution on the Delivery Page

Out of the box, the Format Resolution setting under the Render Settings on the Deliver page tracks the timeline resolution whenever “Match timeline settings” is switched on in the Output Scaling Preset within the Image Scaling panel of the Project Settings. Picking a fresh resolution from the “Set Resolution to” drop-down menu overrides the existing Format Resolution setting ahead of rendering. With this control you can stack several jobs, each assigned its own resolution, so that one render session outputs multiple formats. To learn more about rendering and preparing jobs for the Render Queue, consult Chapter 186, “Using the Deliver Page.”

### Rendering Sizing Adjustments and Blanking

As you render your finished output, you get to decide whether the sizing operations already performed should be “baked in.” Suppose, for instance, you've built a complete batch of specific sizing tweaks for a program's clips, but then someone asks that the project, together with its media, be rendered as separate individual clips for round-trip re-delivery back to the editor so further work can happen. Here you can opt to render the sizing into the final media or leave it out. Whether sizing ends up baked into your final media hinges on the “Disable edit and input sizing” checkbox located in the Advanced Settings options of the Render Settings panel. Sizing and blanking can be disabled whether you're rendering the current timeline as one clip or rendering individual clips. With “Disable sizing and blanking output” switched off, the following all get rendered into the finished media through the optical-quality sizing algorithms DaVinci Resolve provides: Output Blanking; the Cut and Edit page sizing adjustments; the Color page Input plus Output Sizing adjustments; and Image Stabilization. That's the right choice once your sizing tweaks are approved and final and you intend to “bake” them into the media you're handing over. With “Disable sizing and blanking output” switched on, these go unrendered: Output Blanking; the Cut and Edit page sizing adjustments; the Color page Input plus Output Sizing adjustments; along with Image Stabilization. Each clip then renders either at the source resolution when “Render at source resolution” is enabled in individual clips mode, or at whatever resolution the timeline or project currently specifies. Even so, the sizing tweaks you made will travel out as part of the XML or AAF file you're exporting. That suits workflows in which the editor intends to keep tweaking sizing after you've passed off the graded project, working relative to the clips' original size. Bear in mind that when you want Input Sizing tweaks rendered into whatever media you're putting out, the “Force sizing to highest quality” checkbox makes certain DaVinci Resolve applies the top-quality sizing setting even when you've momentarily picked a faster-processing option to suit a slower computer. NOTE: “Disable sizing and blanking output” leaves untouched any transform operations taking place inside the Fusion page. Those go on being applied to the final output.
