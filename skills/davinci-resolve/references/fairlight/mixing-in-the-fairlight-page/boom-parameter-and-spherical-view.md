### Boom parameter

TIP: Hold the Shift key down to lock left/right position while you work the panning. Any rotary control can be reset to its default value with a double-click.

### Spherical View

Clicking the Spherical button atop the 2D Panner moves the interface into Spherical view, which carries the controls below, two of them parameters for Ambisonic panning:

### The Panner control window – Spherical view

- Azimuth: With this control you spin the sound source around the sphere’s circumference.
- Distance: This control sets how far the signal source sits from the listening position at

the sphere’s center.

- Rotate: This controller spins the sound source (or sources) around the listening position at the

heart of the sound field.

- Spread: With multichannel audio, this sets the spread or distance separating the sound

sources. It’s gauged on a numeric scale of 1-99, on which 1 carries the label PNT (“Point”) and 99 carries the label FULL.

- Size: As of this writing, this parameter isn’t active. 2D: As of this writing, this parameter isn’t active.
- Boom: This sets the send level into the LFE portion of the mix (the Low-Frequency Extension subwoofer system).
- On: Switches the Boom output on.
- Pre: Sends the LFE signal pre-fader.

### 3D Panner Controls

DaVinci Resolve ships with both 3D Cartesian and Spherical flavors of this Panner, giving you spatial audio positioning while you work in advanced surround formats — among them Dolby Atmos, Ambisonics, Auro 3D, and NHK 22.2.
