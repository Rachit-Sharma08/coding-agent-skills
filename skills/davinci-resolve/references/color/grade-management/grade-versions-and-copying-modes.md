### Grade Management

On the Color page you have a wide assortment of tools for storing grades, duplicating grades, forming and editing clip groups that pool a shared grade, propagating grades and tweaks, and keeping track of several grade versions per clip. Each of these workflows lets you speed up by reusing effort you have already invested so it applies to additional clips that would gain from identical tweaks, or by pushing a change out to many clips simultaneously.

### Using Versions to Manage Grades

Speedy work depends on becoming fluent with the many grade management capabilities that ship inside DaVinci Resolve. The intent of these tools is to let you duplicate and propagate grades to single clips, across hand-built clip groups through the Node Editor’s Clip mode, or across clips that link themselves automatically because they come from one shared source clip in the Media Pool (with Remote versions). Every clip supports keeping several grade versions, and you also get assorted controls for previewing, overwriting, and appending those versions.

### Choosing to Copy Grades Manually or Automatically Using Versions

Every grade you assign to a clip counts as a version. A single clip may hold several versions, yet only one of them is active at any moment. Out of the box, the initial grade given to each clip on a timeline becomes a local version called “Version 1.” The version name and/or number for a clip shows up below the clip thumbnail on the right side. The version name, plus a roster of every other version presently open to that clip, is also visible if you right-click a clip in the Timeline and read the version names listed below the Local Versions submenu.

Picking grade versions by way of the Timeline thumbnails NOTE: A double-click on the version name sitting under a clip’s thumbnail within the Timeline cycles between the version names, the clip names, and the codec belonging to each clip. DaVinci Resolve offers two distinct version types, and each one delivers its own approach to grade management plus linking across a project’s clips and timelines. Local versions: This is the standard grade management approach. Clips on local versions stay unlinked, so every clip carries its own grade that no other clip in any other timeline shares. Altering the grade of a clip on a local version leaves every other clip in that project untouched. Remote versions: A different grade management approach you can switch on. Every clip on remote versions drawn from one shared source clip in the Media Pool gets linked automatically, throughout all timelines, and they all share a single grade set.

When you grade your whole project with local versions, there is no risk that one clip’s grade gets unintentionally pushed onto other clips that merely originate from the same Media Pool file, which can simplify your work. The trade-off is that any grade you wish to reproduce has to be copied by hand, even between clips that obviously share the same take or angle. A group is always available to pool one grade across clips on local versions, yet that adds an additional step. If you flip over to remote versions instead, you enter a mode in which clips on remote versions sharing one media file get bound together automatically. That hands you a handy shortcut while grading a program, because a grade put on one linked clip is duplicated onto every other clip in its link set, which proves useful when grading a run of headshots scattered across a program that all stem from one interview take. Remote versions also help when you bring in a fresh cut of a timeline that has already been graded. With remote versions you can configure your project so freshly arriving timelines relink themselves to the grades of the earlier timeline. The single downside to remote versions is that once you discover you must apply individual tweaks to clips that are linked, you face the additional step of either spawning another version or moving that clip onto a local version so its tweak stays isolated. More on this appears later in the chapter.

### Mixing Versions

Any clip can hold several local versions and remote versions simultaneously; the choice of which to use is yours. The best versioning approach hinges on the kind of project you are doing, how the footage was captured, and your personal work habits. The sections below describe where the workflows diverge.

### Using Local Versions by Default

Because local versions are the standard grading approach whenever you spin up a new project (assuming you haven’t altered your settings presets), nothing needs to be done up front to switch on this mode. True to the label, local versions stay local to the Timeline that contains them, so local versions never ripple out to linked clips and never get shared across separate timelines. That keeps it simple to steer clear of grades getting copied by accident when you’d rather they weren’t, though you forfeit the conveniences automatic linking would have offered. That said, you can always move a timeline’s clips onto remote versions should you reconsider, whether one at a time or every clip together.

### Using Remote Versions to Enable Automatic Linking

With remote versions, all clips originating from one shared source media file in the Media Pool share their grades on their own, whether inside one timeline or spanning several timelines within the same project. To unlock the convenience of remote grades, though, you must switch DaVinci Resolve into this working mode through the Settings window. To enable remote grades to be used:

- Head into the Project Settings, bring up the General Options panel, and under the Color section disable “Use local version for new clips in timeline”. Disabling this checkbox takes effect only for clips dropped onto Timelines after that point. To monitor which clips are on remote versions, watch for the (R) that shows up when you double‑click the region beneath the thumbnail to conceal the codec name in the Thumbnail timeline.

Switching off “Use local version for new clips in timeline” so remote grades become the default How Automatic Linking Works After clips carrying remote versions land in a timeline, any additional clips anywhere that: a) Also rely on remote versions, plus b) Point at the same file in the Media Pool get linked. Select a clip on a remote grade within the Color page that has auto-linked to one or more clips, and a small “linked” badge appears beside that clip’s timecode over in the Thumbnail timeline.

The linking arrow indicates that this clip draws on an identical source to whichever one you’ve picked on the Timeline TIP: Within the Color Page toolbar, the Timeline Filtering drop-down offers a choice named “Common Media Pool Clips” that narrows the Timeline view down to only those clips linked with whatever clip you’ve currently got selected. Tweaks you make to a remote version on one linked clip ripple on their own to every other clip it links to, which can rescue a tremendous amount of time as you ramp up on a new program. As an illustration, when every reverse angle from one take within a given angle of coverage links itself automatically through remote versions, then the grade you set on a single reverse angle clip will ripple across every other reverse angle clip down the Timeline.

A Timeline displaying three clips that auto-linked, with the codec names tucked away so the (R) marking these clips as remote-graded becomes visible As long as remote versions stay enabled, linked clip relationships can arise in still other ways. Suppose that after conforming an AAF, XML, or EDL you pressed the Split Clips button in the Color page to break one conformed clip into several; each clip you split would link up, since they too would draw on the same source media in the Media Pool. Lastly, automatic linking happens as well for clips that show up across several timelines that also rely on remote versions. Consequently, the grade you set on one linked clip ripples on its own to every other clip it links to. NOTE: Media management or media consolidation tasks that break large source media files apart into many separate media files will undo automatic linking inside one timeline, because each clip will then be conformed to its own separate media file. Starting with Remote Versions, Then Switching to Local Versions You can fuse the strengths of remote and local versions into one workflow, exploiting your freedom to move between the two at will. Because remote versions make duplicating grades among similar clips effortless, you might begin on remote versions, grading your way along the Timeline until you reach the stage where you must begin applying far more targeted changes to single clips. From there, it is simple to either move each linked clip needing an individual tweak onto a local version, or invoke the Copy Remote Grades To Local command (covered later) to copy each clip’s present remote version into a local version, after which you can perform every specific adjustment you need without fear of changes spreading by accident.

### Creating a Master Timeline

DaVinci Resolve version 9 and prior versions would build a Master Timeline on their own each time you dropped clips into the Media Pool. That behavior shifted with versions 10 and later, which carry no Master Timeline by default. Still, should you wish to build a Master Timeline so you can work with it as you once did, doing so is straightforward. If you’d like a Master Timeline that serves as one timeline always holding every clip presently in the Media Pool, there is a method for creating one. You must do it right away when you create a new project, prior to dropping any media into the Media Pool, though. After you have added one or more clips to the Media Pool, the option that lets you do this will be greyed out.

To create a new Master Timeline: 1 Start a fresh project, bring up the Project Settings’ General Options panel, then within the Color section enable the “Automatically match master timeline with media pool” checkbox. If on top of that you’d like each clip grading on Remote versions by default the way older DaVinci Resolve builds behaved, switch off the “Use local version for new clips in timeline” checkbox. 2 Hit Save. 3 Head over to the Edit page, then pick File > New Timeline (Command-N). 4 Once the New Timeline Properties window opens, switch the Empty Timeline checkbox off, then click Create New Timeline. At this point, next to the new Timeline, a Master Timeline turns up within the Timeline list. After it is built, the Master Timeline holds every clip in the present project’s Media Pool. Should you color correct the clips inside the Master Timeline, you’ll discover just a single version set exists, sitting below the Local submenu of the Color Page timeline’s contextual menu. The key thing to grasp is that local versions within the Master Timeline are actually the remote versions present in every other timeline of that project. Indeed, it would be accurate to say the remote versions found across other timelines are really the Master Timeline’s own versions. Grading a clip in the Master Timeline sends those grades rippling outward to every other copy of that clip, throughout every other timeline inside that project, by way of remote versions. This pooling of remote versions between the Master Timeline and freshly conformed timelines is the reason you can grade a batch of clips you bring into DaVinci Resolve lacking any editorial structure, grade and render offline media, then reimport a project file that relinks to the source clips together with their grades. It is likewise why you can grade clips inside one timeline, then import further re-edited timelines through AAF, XML, or EDL, which automatically take on all remote grade versions built in prior timelines.

### Differentiating Clips with Individual Versions

When you have set DaVinci Resolve to bring clips in on remote versions, occasions arise where you may wish to pause automatic linking. Handy as automatic grade rippling across linked remote versions can be, there are plenty of situations where you’ll need to halt it. As an example, if the Media Pool holds a source media file carrying an entire interview, then every clip conformed to that source media gets linked, which is normally desirable because you’d anticipate they’d all carry one grade. Yet if the DP altered the camera’s exposure partway through the interview, leaving some clips brighter and others dimmer, you may end up having to apply distinct tweaks to clips drawn from separate stretches of the interview. One approach, handy on timelines where only a handful of such changes are required, is to spawn a fresh remote version for each clip that demands an individual tweak. Because each version stands as its own grade, and versions with different names never link to each other, this gives a tidy fix. To suspend linking by creating a new remote version: 1 Position the playhead over whichever clip you must adjust on its own. 2 Do one of the following:

- Choose Color > Grade Version > Add (Command-Y).
- On the Timeline, right-click that clip’s thumbnail, then choose Remote Versions > Create New Version.

3 Grade the new version that’s appeared.

This technique serves you well, yet bear in mind that several linked clips carrying the same version number will stay linked to each other no matter what. Put differently, imagine Clip 1, Clip 3, and Clip 5 are linked on the default Version 1, which carries a bold blue grade.

### Three clips automatically linked, sharing a blue grade

Next, you switch Clip 3 onto Version 2 with a separate grade, tinted red. Clip 3 has now broken its link with Clips 1 and 5.

Putting the middle clip of the three onto a separate version with its own remote grade breaks it away from the rest Yet moving Clip 5 onto the red-tinted Version 2 as well leaves Clip 3 and Clip 5 linked to each other, while Clip 1 is linked no longer.

When the last of these three clips is set onto the very same remote version the middle one uses, those two become joined while the first clip drops out Each fresh remote version you build, plus every edit you apply, becomes accessible to all other clips across all other timelines springing from the same source Media Pool clip as the shot in front of you. Still, any clip is free to use any version, and the choice of version on one linked clip does not ripple. As an example, Timeline 1 holds a clip called Max CU, which carries three remote versions. Timeline 5 also holds Max CU, presently set on Version 2. Should you open Timeline 1 and tack one more remote version onto Max CU, that fresh version will likewise be open to Max CU in Timeline 5, yet it will remain set on Version 2.

### Switching Clips Between Local and Remote Versions

You can additionally pause remote version grade linking by moving individual clips onto local versions. That makes it simple to set up an arrangement where some clips are linked and others are not. Bear in mind every clip carries both local and remote versions, so flipping between them costs you nothing.

To suspend linking by setting individual clips to use a local version: Give a clip thumbnail a right-click, drill into the submenu for the matching remote version you’d like duplicated, and choose Copy to Local. The remote version gets copied into a local version, which now stands as the active version in use. You can likewise set every clip across the whole timeline onto local versions. Once you move a full timeline onto local versions, no clip on that timeline links to any other unless you build a group (described later in this chapter). That is the default condition, yet it stays handy even after you’ve adopted remote versions whenever you wish to grade one timeline apart from the rest in a project, say while doing a trim pass for a separate video or stereo 3D format, or while grading another cut like a trailer that draws on the same media but calls for a distinct look. To suspend linking by switching from remote versions to local versions: Give any clip thumbnail a right-click, then pick one of these commands; Use Local Grades: Moves every clip onto its local versions. Where local versions are already set up per clip, those appear. Where none have yet been created, each clip comes up ungraded. Copy Remote Grades to Local: Duplicates each clip’s currently active remote version into a local version. Because Undo only covers actions on a single clip, neither the Use Local Grades nor the Copy Remote Grades To Local command can be undone. Shifting a timeline away from remote toward local versions isn’t permanent, though. At any time you may pick Use Remote Grades to send every clip on a timeline back onto its remote versions. To switch a timeline back to using remote versions: Give any clip thumbnail a right-click, then choose Use Remote Grades. Beyond that, the local grades you created can also be copied into remote grades, handy when you began grading with local grades and now want to move toward remote grading while treating your local grades as the starting position. Keep in mind that doing this on a timeline carrying many clips sourced from the same media means the grade belonging to the final shared clip on the Timeline ends up as the one remote grade applied to those auto-linked clips. To turn every clip’s local grade into a remote grade across the whole timeline you’re on: Give any clip thumbnail a right-click, then choose Copy Local Grades to Remote. When you find yourself flipping between local and remote versions, keep these rules in mind:

- Should you pick Use Remote Grades, adjust those remote grades, then run Copy Remote Grades To Local against that same timeline again, every local version you had graded before gets overwritten. That approach works well whenever you’re unhappy with how your local versions turned out and want to begin afresh by recopying the remote versions.
- Should you pick Use Remote Grades, adjust those remote grades, then pick Use Local Grades, you land back on the local versions you graded earlier, just as they were before Use Remote Grades was chosen. That approach works well whenever you only wish to jump over to your remote versions so the remote versions of particular clips can be copied into local versions.
