### Using Clip Metadata

DaVinci Resolve ships with capable tools for viewing, editing, exporting, and importing the metadata tied to every clip in the Media Pool. After your metadata is well organized, you can lean on it across the Cut, Edit, Color, and Fairlight pages to locate, sort, and arrange your project's clips, which speeds up your work.

### Editing Clip Metadata

No matter whether you brought in media to get ready for editing or imported a project for grading that pulled in media on its own, once clips land in the Media Pool it pays to set aside time to look over your clips and tag them with metadata. At minimum it's worthwhile to open the Metadata Editor — found on either the Media page or the Edit page — and attach details to each clip, including a Description, Shot and Scene designations, Take information, plus handy keywords such as Character Names, Shot Framing, and Interior or Exterior keywords. Feeling especially diligent (or blessed with a dependable assistant), you might press on and record Shoot Day, Camera Type, Audio Notes, and similar useful entries. A good deal of the metadata that proves handy in everyday editing and grading lives in the Shot & Scene group, yet plenty of other worthwhile groups exist that are worth a look. Bear in mind that the more metadata you attach to a clip, the more avenues you gain for building custom Smart Bins (for editing) and Smart Filters (for grading) to pinpoint exactly the clips a given moment calls for. Beyond making it simpler to track down what you're after, this helps you move faster. For instance, with enough metadata in place you can assemble multi-criteria Smart Bins or Smart Filters that surface results along the lines of every tight shot of Sally seated in the diner, or every wide shot showing Antonio out in the parking lot. Working on a documentary, you could just as easily isolate each interview of Louis captured on camera 1, or any B-roll featuring Robyn. All of it lets you track down media faster while editing, or swiftly assemble like clips you need to pair together while grading.

### Automatically Imported Metadata

Frequently, metadata arrives together with the media you've placed in the Media Pool. As an example, footage shot on BMD cameras might carry assorted metadata typed into the camera or generated by it automatically, and that metadata shows up in the Metadata Editor without any effort on your part. In the same vein, Broadcast WAVE files can hold a fair amount of metadata captured during recording, such as scene and take numbers along with channel names identifying each microphone. Still images come in carrying EXIF metadata. Across every scenario, whatever metadata is present accompanies the media and surfaces in the Metadata Editor, supporting workflows in which valuable organizational metadata gets logged on set during the shoot or right after ingest.

### Using the Metadata Editor

Each time you pick a clip in the Media Pool, its editable metadata is shown in the aptly titled Metadata Editor (provided that panel is visible). This editor lets you refine a project's clip metadata further, recording on-set details that prove helpful down the line during editing and finishing. Out of the box, clips first show a metadata set named “Clip Details,” which lists some of the clip's most basic facts such as start and end timecode, duration, bit depth, and the like. Given how many metadata fields exist, a pair of drop-down menus at the upper right of the Metadata Editor let you swap which metadata set you see.

- Metadata Presets (to the left): When you've built your own custom metadata sets through the Metadata panel of the User Preferences, this drop-down chooses which one to display. Oddly enough, its starting value is “Default.”
- Metadata Groups (to the right): This drop-down lets you move between the assorted metadata groups on offer, each grouped for particular tasks or workflows.

### Metadata categories drop-down menu

To view a full rundown of every metadata item in a clip, pick All Groups. Otherwise, selecting any particular metadata set trims your focus down to just those pieces of information. To edit metadata for a single clip: Pick any clip in the Media Pool and adjust whatever metadata fields you need. Your edits save right away.

To edit metadata for multiple clips: 1 Pick a metadata set from the drop-down in the Metadata Editor. 2 Select more than one Media Pool clip — Shift-click, Command-click, or drag a bounding box across them. 3 Adjust whichever metadata fields you'd like. Any metadata field you touch has its checkbox switched on automatically. 4 Once finished, press the Save button along the bottom of the Metadata Editor. After editing metadata for several clips together, you'll be asked to save if you make a fresh selection in the Media Pool before pressing the Save button.

### Editing Keywords

Although most metadata in the Metadata Editor is entered through text fields, checkboxes, or multi-button selections (Flags and Clip Color, for example), the Keyword field stands apart by relying on a graphical “tag” style of data entry. Its aim is to keep keyword spelling consistent by letting you readily draw on both a built-in roster of standardized keywords and the keywords you've already applied to other clips. After they're in place, keywords prove tremendously handy for searching and sorting within the Media Pool, for building Smart Bins on the Media and Edit pages, and for feeding Smart Filters on the Color page. Earning these payoffs by adding and editing keywords is straightforward and mirrors how you enter metadata variables. For further detail on metadata variables, refer to Chapter 16, “Using Variables and Keywords.” To add a keyword: 1 Click into the Keyword field of the Metadata Editor and start typing the keyword you have in mind. The moment you type, a scrolling list pops up listing every keyword reachable through the characters you've entered. 2 To locate a particular keyword in that list, begin typing its name and the list narrows itself automatically to keywords containing the characters you've typed. Pick the keyword you want with the Up and Down Arrow keys, then press Return to add it.

The keyword list that appears when you type within the Keyword field The instant you add one or more keywords, they show up as a graphical tag. To revisit any keyword, just click somewhere inside the Keyword field to edit it.

To edit a keyword: Double-click any keyword to make it editable, change it like you would any other text, and press Return to turn it back into a graphical keyword tag. To remove a keyword: Click a keyword to highlight it, then press Delete. TIP: On macOS, any color tags assigned and defined within the Finder can be brought in automatically as keywords next to their media clips. To switch it on, find the User Preferences, open the Editing section's General Settings panel, and check the “Import Finder tags as Keywords” box there.

### Adding and Populating Custom Metadata Fields

On the Media and Edit pages you can attach your own custom Metadata fields to clips. Such fields may be scoped to the current project alone or shared across all of your projects. The available field types are:

- Text Input: A single-line field for typing text.
- Text Area: A field spanning several lines for typing text, suited to richer metadata.
- Numeric: A field that takes a numeric value.
- Timecode: A field that takes one timecode entry.
- Checkbox: A plain on/off checkbox.

To create or change custom metadata, pick Create Custom Metadata from the three dot options menu on the Metadata tab.

Locating the Create Custom Metadata choice within the three-dot menu on the Metadata tab After that, set the field name and field type and decide whether the fields should appear across every project. Repeat the process as needed until all your custom metadata fields exist.

### The new custom metadata dialog

To Manage Custom Metadata so you can reorder, edit, and delete custom metadata types, pick Manage Custom Metadata from the Metadata three-dot option menu, then apply your changes within the Manage Custom Metadata interface.

### The Manage Custom Metadata interface

After the fields are set, you fill them in exactly as you would any other metadata field in the Metadata Tab. To show only the custom metadata fields, open the group filter dropdown menu at the upper right of the Metadata tab and pick Custom.

### The populated Custom Metadata fields

Metadata fields can be scoped to the current project, or you can tick “show in all projects” to make a field appear throughout all of your projects. Project metadata is stored with the project and reachable by everyone working on it. Cross-project metadata definitions are retained and shown across projects and project libraries on your behalf. Once you enter a value into a cross-project metadata field, it gets stored to the project and becomes reachable by the project's other users. The custom metadata panel presents a superset combining project-persisted custom metadata with cross-project metadata fields.

### Editing Metadata Using the File Inspector

The Inspector's File tab offers a single, consolidated place to view and edit a slice of a clip’s most frequently used media file metadata. It's readily available from the Inspector on every one of the Media, Cut, Edit, and Fairlight pages. This tab is made up of the following parts:

- Clip Details: Shows information about the clip’s data format (codec, resolution, frame rate, and so on).
- Metadata: Shows a trimmed-down selection of common metadata fields for fast entry.

Timecode: The clip's starting timecode. You can edit this field to set the clip’s starting timecode by hand. Date Created: When the clip came into being. Edit this field to set the clip’s creation date by hand. Camera: Fills in the Camera # metadata. Reel: Fills in the Reel/Card ID. Scene: The clip's Scene number. Shot: The clip's Shot letter/number. Take: The clip's Take number. Good Take: A checkbox marking whether the clip is a good or circled take. Clip Color: Give a clip a particular color that carries through to the Timeline. Name: The clip name field, which you can type in yourself. Comments: Attach a text description to the clip.

- Auto Select Next Unsorted Clip: With this box ticked, pressing return after filling a metadata field jumps the selection to the next clip in the Media Pool and drops the cursor back into the same field. This enables fast, one-after-another metadata entry without manually clicking to load each clip in the Media Pool. The Next Clip button advances to the next clip in the Media Pool no matter what state the checkbox is in.
