### Thumbnail, List, and Metadata Views in the Media Pool


There are several familiar ways to look through what's inside the Media Pool: Thumbnail view: An icon stands in for each clip, and the file name sits just below it. Hovering the pointer across a clip's icon prompts DaVinci Resolve to scrub through it on its own, revealing what's inside. On top of that, a Clip Info drop-down menu shows up at the bottom-right corner. Clicking the Clip Info drop-down brings up an overlay that lists the key details for the clip. While in Thumbnail view, the Sort Order drop-down lets you set the order in which clips are arranged. List view: Here a clip takes the form of an entry in a text list. Several columns of information also appear, arranged beneath headers. Clicking a header sorts the list by that column, either ascending or descending. Metadata view: Each clip gets its own card, showing a thumbnail alongside basic clip metadata. This mode aims to surface more metadata than a thumbnail does while staying more focused than the List view. To read further about navigating what's in the Media Pool, refer to Chapter 18, “Adding and Organizing Media with the Media Pool.”
