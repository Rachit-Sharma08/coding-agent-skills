### Remapping a Command to One or More Keys

Reassigning the keyboard mapping of any command is straightforward. Where needed, you can even bind one command to several keys. Within DaVinci Resolve, an action may apply across the whole application or be confined to the Media Pool, the Timeline, or another panel. The right column in the key customization dialog lists both application-level and panel-level actions. While a panel holds focus, hotkeys give precedence to that panel's local actions. Because of this, the same shortcut can serve simultaneously at the application level and inside each individual panel. To revise the keyboard shortcut tied to a given command: 1 Locate the command you intend to remap within the Commands list by picking a category. Where helpful, the Search field narrows things down. Whether a command applies broadly to the whole application or narrowly to one panel is governed by what you've highlighted in the list. a) When the key you mean to assign should function across the whole application, pick a menu name listed beneath the Application category of the Commands list. Every menu displays all of its associated commands and supports its own search. b) When the key you mean to assign to this command should stay specific to one panel, pick a panel from the Panels category below. Every panel displays all of its associated commands and supports its own search. 2 Click inside the Keystroke column of the list, just right of the command, and once a selection appears, type a fresh character together with whatever combination of modifier keys you prefer.

Clicking to select a keyboard shortcut you want to modify

Be aware that whenever you remap a key already bound to a different command, a warning surfaces telling you the key you're reassigning is taken by another command, offering you the option to back out and adjust your bindings as you prefer. The alert that appears when one key gets pointed at more than a single command Although you can dismiss the warning and proceed with the binding, sharing one character or combination across multiple commands can lead to trouble, which is why a warning badge shows up beside the commands involved. Clicking that badge quickly reveals the source of the duplication by lighting up the relevant keys on the keyboard, letting you reassign whichever command needs it. To resolve a shortcut conflict:

- Click the yellow warning icon beside the action. Doing so lists every action bound to that hotkey in the left panel.
- Click the other clashing actions at that same level to surface them in the right pane.
- Adjust or clear those values so they no longer collide with your new key binding. 3 (Optional) You may also bind more than one keyboard shortcut to a single command. As an example, should you want to add keys from the numeric keypad of an extended keyboard alongside other keys for a given command, you can arrange this by clicking the "plus" button to the right of a shortcut that's already assigned. A second highlight then appears, into which you can type whatever extra character or combination you'd like for the additional binding. There's no limit to how often you repeat this. Once finished, every keyboard shortcut bound to that command is shown, divided by commas.

You can map multiple keys to the same command, if necessary

4 Once you've completed your shortcut edits, click the Save button at the lower right of the Keyboard Mapping list, then click Close to dismiss the window. Picture, as an example, that you assign 'Option-G' twice: a) once to Clip Attributes (which lives in the Media Pool), and b) once more, this time to the command Mark > Add Flag > Green that spans the whole application. While your focus rests on the Media Pool, you won't be able to drop green flags with a hotkey. Instead, you'll have to add them by hand through the Mark menu. On top of that, the application-wide Color > Nodes > Add serial node with polygon power window shares that same hotkey (Option-G), so action b prompts the key customization dialog to raise a warning naming the conflicting action and to place an icon on both actions. Should you save this configuration as a preset (conflicts and all), DaVinci Resolve still attempts to interpret your shortcuts sensibly. As an illustration, on the Edit and Fairlight timelines, Option-G drops a green flag (since color node actions don't apply there). Yet on the Color page, Option-G could mean either action, and the user has to clear the conflict for the action to behave properly.

### DaVinci Resolve Extras Download Manager

As DaVinci Resolve grows to bundle in more AI-driven models, that growth comes at the cost of application file size. Such AI models are typically hefty datasets that many users won't want or have any need for. To ease that choice, DaVinci Resolve provides the Extras Download Manager, letting you cherry-pick which optional capabilities to bring into DaVinci Resolve. You'll find the Extras Download Manager at DaVinci Resolve > Extras Download Manager.

### The Extras Download Manager

Working with the Extras Download Manager is as easy as browsing the packages on offer and choosing download. Within that same interface, you can delete a package by clicking the trashcan icon beside the package name. The downloading proceeds in the background so you can keep working uninterrupted. Periodically these packages get refreshed, and this is where you'll be alerted whenever your installed package has fallen behind. At present, the Download Manager offers packages for AI Voice Training and Extended AI Transcription Support Languages.
