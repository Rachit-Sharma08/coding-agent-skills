### The Render Queue

The Render Queue gathers every job you've lined up for file-based rendering. Since each job can hold its own range of clips and render settings, you can render multiple sections or clips of a timeline, the same timeline pushed out to several formats, or several timelines outright. The Render Queue can also be set to display either only the jobs in the current project or all the jobs queued and saved across every project for the current user.
