### Conforming EDL Files

Of all the project exchange formats, the edit decision list (EDL) is the most universally shared baseline, and nearly every professional post-production tool can write and read projects in it, among them Media Composer, Autodesk Flame Premium, and the legacy Final Cut Pro 7. The workflows in this chapter all deal with bringing in and conforming timelines via the EDL format.

DaVinci Resolve handles the CMX 3600 format for both EDL import and export. Part of why EDLs are so widely understood is how long they've been around; assorted EDL formats have served the industry for decades. Their plainness helps too. As DaVinci Resolve employs them at least, EDLs carry only a slim slice of editorial data: clip ordering, clip name (through embedded comments), video transitions (cuts or dissolves), and linear speed values (a fast-forward or slow-motion percentage). EDLs also carry the constraint of holding just one run of shots along a single video track. When you have to relocate projects holding several audio and video tracks, you can write out each track as its own EDL from the source application, then right-click, within the Media Pool, the timeline you intend to bring them into and run the Timelines > Import > EDL to New Track contextual menu command, importing every individual EDL onto a new track of one timeline in DaVinci Resolve. A later part of this chapter walks through that. NOTE: Even though the EDL format recognizes an assortment of SMPTE-defined video transition codes, every EDL transition becomes a cross dissolve of matching length once inside DaVinci Resolve. For anyone new to the EDL format, every edit appears as a numbered event carrying these fields: reel number, edit type, then source timecode (In and Out points) plus record timecode (In and Out points). Below is an example of a basic four event EDL: TITLE: Pool Shark Edit FCM: NON-DROP FRAME 001 REEL_ONE AA/V C 10:59:23:01 10:59:28:16 01:00:00:00 01:00:05:15 002 REEL_ONE AA/V C 11:39:48:15 11:39:51:13 01:00:05:15 01:00:08:13 003 REEL_ONE AA/V C 13:16:30:21 13:16:34:19 01:00:08:13 01:00:12:11 004 REEL_ONE AA/V C 14:09:43:16 14:09:44:20 01:00:12:11 01:00:13:15 Because DaVinci Resolve was built from the start around importing and exporting EDLs, you have a number of ways to bring projects in through them. Whichever route you take, the media an EDL points to has to be added to the Media Pool before that EDL can be imported. There are three primary workflows:

- Conforming EDLs to individual media files: Bringing in an EDL whose references point to a set of separate media files already loaded into DaVinci Resolve.
- Preconforming, or “notching,” a “flattened” master media file using an EDL: Bringing in an EDL whose references point to a “flattened” master media file. A flattened master media file results from writing out a whole sequence from an NLE as one self-contained media file.
- Importing an EDL directly to a new track of an existing edit: When the project you're bringing in spans several video tracks and EDLs are your only avenue, write out each track of the source project as its own EDL, then bring each one into DaVinci Resolve straight onto extra tracks of the same Timeline. This also serves workflows in which effects clips live on a separate track built elsewhere, which you can then import straight into a graded timeline to drop in many fresh effects clips in one go.

Through the Timeline Import dialog you can pick several XML, AAF, FCP XML, or EDL timelines together (in any mix). Those chosen timelines come in one after another, pausing each time the OK button is clicked so you can set separate Import Settings per timeline. What follows describes the various ways EDLs serve you in DaVinci Resolve.

### EDL Export of a Project and Its Media

With EDL workflows, you'll want to confirm that every clip in your cut sequence, plus each source media file tied to it, carries a fitting reel number/reel name and genuine timecode baked into that file. While conforming EDLs, DaVinci Resolve depends on reel names and correct timecode to properly conform the imported EDL timeline against media in the Media Pool. Exporting an EDL that DaVinci Resolve can conform without trouble means each NLE has specific settings worth using. The main supported format is CMX 3600, though DaVinci Resolve handles the DEDL format that both Smoke and Flame produce as well. On top of that, most editing tools let you decide which video and audio tracks get exported and how the start timecode for the chosen run of clips is treated. As a rule, you'll want the exported start timecode to line up with your sequence timeline. Other particulars do shift between applications, however. As one example, exporting an EDL from Media Composer via Tools > List Tool means confirming the Active Setting reads Default EDL and the Output Format reads CMX_3600. Exporting an EDL from Premiere Pro gives you the choice of turning on Use Source File Name and Include Transitions. When you export an EDL from the legacy Final Cut Pro 7, the steps are setting Reel Conflicts to Generic Edits and switching on the File Names checkbox. Most programs offer further optional settings, EDL notes of several sorts among them, but for a tidier, more legible EDL you're free to switch these off.

### Conforming EDLs to Individual Media Files

What's good about working from discrete media files is that they hold the “purest” form of the media, with no effects (dissolves, superimpositions, and so on) “baked” into the imagery to trip you up while grading. 1 Ahead of bringing in any media, confirm the “Timeline frame rate” pop-up menu, found in the Master Settings panel of the Project Settings, holds a frame rate matching both your project and media. Otherwise the EDL's timecode ends up misread. 2 Open the Media page, lean on the Media Storage browser to locate whatever media belongs in the project, then drop it into the Media Pool through a right-click on the containing directory and a choice among these commands: Add Folder into Media Pool: Pulls every compatible media file inside that folder into the Media Pool, leaving subfolders untouched. Add Folder and SubFolders into Media Pool: Pulls every compatible media file from that folder plus all of its subfolders into the Media Pool. Add Folder Based on EDLs into Media Pool: Has you choose an EDL, then brings in only the media that EDL references, scanning solely the chosen folder for it. Add Folder and SubFolders Based on EDLs into Media Pool: Has you choose an EDL, then brings in only the media that EDL references, scanning the chosen folder together with all of its subfolders for it. TIP: The “Add Folder...Based on EDLs” commands prove handy for efficiently grabbing only the media you require into the Media Pool whenever many terabytes of unmanaged source media sit around, most of it never used.

- From any page, choose File > Import Timeline (Shift-Command-I).
- On the Edit page, right-click any spot inside the Media Pool, then pick Timelines > Import > AAF/EDL/XML/DRT/ADL/OTIO. A dialog opens asking you to “Select a file to import.”

### Preconforming “Flat” Media Files to EDLs

Readying a cut sequence for grading, together with every separate clip of media, can eat up time on effects-heavy projects, or it might be a pointless step for a project carrying no effects at all. For those cases, exporting a flattened master media file that DaVinci Resolve can split back into its separate clips is often quicker and simpler. This approach echoes a more conventional tape-to-tape workflow, save that you're working from a digital master instead of a tape‑based one. The simplest route is the Preconform button on the Edit page, which splits one master file you've brought into the Media Pool back into separate clips inside a new timeline.

Here's how to preconform a flattened master media file to an EDL: 1 On the Media page, navigate with the Media Storage browser over to the exported flattened master media file that holds the entire program, then double-click so it lands in the Media Pool. 2 Right-click any empty area of the Media Pool, then pick Timelines > Import > Preconformed EDL. 3 Within the “Select an EDL file” dialog that opens, find the EDL that lines up with the flattened master media file you'd exported, choose it, then click Open. 4 Within the “Parse preconform options” dialog that opens, give the new Timeline a name, then click OK. A new Timeline shows up in the Media Pool list, and opening it on the Edit page presents the flattened media file with cuts placed on its video track corresponding to those of the EDL you chose, set for more editing and grading. The audio stays uncut, on the assumption you're most likely concentrating on grading the visuals here rather than re-cutting the audio.

### Override Input Color Space of Clips in Preconform Workflows Using Color Management

Once you've preconformed a flattened master media file through an EDL with the File > Import Timeline > Preconformed EDL command, and Resolve Color Management or ACES is active on your project, each clip's Input Color Space across the resulting Timeline can now be set independently. To do that, open the Color page, right-click the clips you'd like to adjust, and pick an option out of the Input Color Space submenu within the contextual menu. This helps in workflows where the flattened media file you got was output with clips spanning different color spaces, such as a mix of Rec. 709 media alongside log-encoded clips of various sorts.

### Conforming “Flat” Media Files Using Split and Add

A second way to conform an EDL against a flattened file uses the “Split and Add” command on the Media page to break one or more master media files into separate clips matching an EDL's, then bringing the EDL in on the Edit page as a follow-up step. This route helps when clips sit across different folders or volumes that you want conformed to one EDL. As an instance, most of a program's first reel might have gone out as a single flattened file, while the matching EDL may call for one more folder of effects clips added to the Media Pool for full conforming. To split a flat media file on the Media page and bring in its EDL on the Edit page: 1 Ahead of bringing in any media, confirm the “Timeline frame rate” pop-up menu, found in the Master Settings panel of the Project Settings, carries a frame rate aligned with your project. 2 On the Media page, navigate with the Media Storage browser over to the flattened master media file that holds the entire program. 3 Choose the flattened media file, give it a right-click, then pick “Split and Add into Media Pool.” 4 Within the “Select EDL files for splitting clips” dialog that opens, find the EDL that lines up with the flattened master media file, choose it, then click Open.

5 Pick the project's frame rate from the File Conform Frame Rate dialog that appears. That frame rate ought to match the “Timeline frame rate” pop-up you set back in step 1. 6 Choose the suitable options within the “Enter handle size for splitting” dialog that opens: Handle size in number of frames: Type how many frames get tacked on as handles around the clip's first and last frame. It's handy whenever the “Split and Add into Media Pool” command pulls in just the referenced stretches of a directory full of separate media files. Split Unreferred Clips: Handy when the referenced media files carry stretches that no event inside the splitting EDL “refers to.” Ticking this checkbox drops each such unreferred clip stretch into the Media Pool as a standalone clip, available later if needed. 7 Click Split & Add. The Media Pool populates with individual stretches of the flattened master media file, every one tied to an event in the EDL you split against. 8 Bringing in the matching EDL to build a timeline from this media is done one of these ways:

- From any page, choose File > Import AAF, EDL, XML (Shift-Command-I).
- Right-click any empty area of the Media Pool, then pick Timelines > Import >

AAF/EDL/XML. 9 Within the “Choose a file to import” dialog that opens, find the EDL that lines up with the flattened master media file, choose it, then click Open. 10 Pick whatever options you need from the Load EDL dialog that opens (its defaults should serve fine), then click OK. The Master Timeline along with the timeline you've just imported show up in the Media Pool, the Conform EDL list refreshes with events from the imported EDL, and the Timeline editor displays the cut clips, set for grading. Any clip that couldn't be tied to a matching file in the Media Pool shows a red x, flagging it as unconformed.

### Importing an EDL to a New Track

This final procedure covers adding an EDL not as a standalone new Timeline but as one more video track on an existing Timeline. Plenty of situations call for it. As an example, when you must bring a multi-track project into DaVinci Resolve from a tool that can't write either AAF or XML project exchange files that DaVinci Resolve reads, several EDLs do the job. Just write out each track of the source project as its own EDL, then bring each one into DaVinci Resolve as extra tracks of the same Timeline. This also serves workflows where effects clips live on a separate track built elsewhere, which you can then import straight into a graded Timeline to drop in many fresh effects clips at once. Here's how to add an EDL onto a fresh track within an existing timeline: 1 Throughout this routine you're free to load whatever media the upcoming EDL needs into the Media Pool first, or to add that media after the EDL arrives. Either order works. 2 On the Edit page, choose a timeline within the Media Pool, give it a right-click, then pick Timelines > Import > EDL to New Track. A dialog opens asking you to “Choose a file to import.” 3 Find the EDL file you mean to use, choose it, then click Open. 4 A fresh video track gets made above any tracks that already exist, and events from the chosen EDL load straight into it following their record timecode positions. If you brought in the media the new clips need at the start of this procedure, that media ought to be conformed. If not, you'll have to hunt down the media files the new unconformed clips need and add them to the Media Pool now.
