### Conforming and Relinking Clips

Regardless of whether the project you bring in is a DaVinci Resolve project or a project exchange file produced by some other application, you will have to handle relinking media files within the Media Pool and reconforming timelines to media files that are either identical or compatible, whether those files already sit in the Media Pool or still have to be brought in from disk. The rules governing how DaVinci Resolve conforms clips so they line up with timelines are covered in this chapter, which also lays out the many ways you can govern clip linking and timeline conform, along with how to tackle the problems that crop up through the many problem-solving techniques DaVinci Resolve puts at your disposal.

### Conforming and Relinking Media

A rich set of tools is supplied by DaVinci Resolve for handling the connection between clips sitting in the Media Pool and clips sitting in timelines, as well as the links tying each clip to the media file it points at on disk. These tools serve you when steering varied project workflows, or when sorting out trouble that may surface as you import project files of any format coming from assorted sources. Every approach DaVinci Resolve offers for conforming clips and relinking media is laid out in this section. Further detail on the clip metadata that establishes which clips correspond to which media appears further along in this chapter.

### Conforming and Relinking During Project Import

Bringing in an AAF or XML file gives you the chance to relink the clips landing in the Media Pool to their matching source media files on disk during the operation. One automatic consequence is that the imported timeline gets conformed to the Media Pool's clips, leaving you with a Media Pool stocked with clips plus a layout of those clips inside the imported timeline. Since this all tends to occur simultaneously, the line between a timeline's tie to the clips in the Media Pool and each clip's tie to its matching source media file on disk is easily blurred. Importing an EDL spells this process out more plainly, because you have to bring every clip you need into the Media Pool first, taking care that they carry the right reel names and timecode. Doing so forges the link joining the Media Pool clips to the source media on disk. After that you import the EDL as a separate step, producing a timeline that tries to reconform itself to the Media Pool clips through reel name and timecode data.

### Conforming and Relinking Existing Timelines and Clips

Plenty of situations may lead you to reconform or relink media well after you've begun editing or grading a project, so further tools are provided by DaVinci Resolve to ease these workflows too. As one case, you might have launched a project on placeholder VFX or stock footage clips, yet later have to swap in finished versions of those very shots. Alternatively, you might have chosen to cut a project using transcoded copies of the camera raw media files handed to you, only to later opt for switching one clip or every clip in the timeline over to the original camera media for grading and finishing instead. A broad assortment of tools backs these workflows and others in DaVinci Resolve.

### The Difference Between Conforming and Relinking

Although people frequently treat the pair of terms as interchangeable, conforming generally describes the act of matching a timeline's clips to their proper source clips within the Media Pool, whereas relinking generally describes the act of matching a source clip in the Media Pool to the media file it corresponds to on disk. This shift is recent, brought about by a widening of the relinking and reconforming options, so the author apologizes should this usage prove inconsistent at times.

### The Difference Between Unlinked and Missing Clips

It may come across as nitpicking, yet a meaningful distinction separates clips that are unlinked from clips that are missing as far as the bond between Media Pool clips and timeline clips goes. To begin with, these two "offline" clip states each present differently within the timeline, and those differences run deeper than appearance.

On the left, a missing clip in the Timeline set beside an unlinked one in the Timeline on the right. The term unlinked clip refers to a clip that is present in the Media Pool but has severed the link to its matching media file on disk. Even so, unlinked clips retain their metadata, keep their connection to the instances of that clip cut into your project's timelines, and lend themselves to easy relinking against media files whose file names and timecode match through the Relink command (covered later), or to reconforming against earlier-imported or freshly-imported clips inside particular bins of the Media Pool via the Reconform From Bins command (also covered later). Missing clips are absent from the Media Pool entirely, though clips marked missing can nonetheless show up in your project's timelines. Because missing timeline clips lack any matching source clip in the Media Pool, the timeline clip carries no metadata visible in the Metadata Editor, and any remote grades attached to that source clip are gone. To read further on remote grades, turn to Chapter 142, "Grade Management." There are two routes for repairing missing clips within a timeline:

- Should the "Automatically conform missing clips added to Media Pool" setting be turned on within the General Options panel of the Project Settings, all you do is reimport the matching source clips into the Media Pool, whereupon they get conformed automatically to missing timeline clips whose timecode and file names align (this happens solely at import time and won't operate on matching clips already present in the Media Pool). Bear in mind that this setting has to be switched off whenever a collaborative workflow is in play.
- Should the "Automatically conform missing clips added to Media Pool" setting be turned off within the General Options panel of the Project Settings, you'll need to bring in the missing clips and then either reconform them by hand one by one to the missing timeline clips through the Conform Lock with Media Pool Clip command, or lean on the Reconform From Bin(s) command, or alternatively the Import Additional Clips With Loose/Tight Filename Match commands, to attempt reconforming the whole batch together.

Whichever route you take to reconform the missing clips, the original remote grades and hand-edited metadata won't return unless you had earlier exported the relevant metadata and grades, in which event you can reimport them and apply them through separate steps.

### Duplicate Clips are Considered Separate Sources

Something else worth grasping is that within DaVinci Resolve, duplicate clips count as wholly distinct from the original Media Pool or Timeline clips they were duplicated from. As an illustration, should you bring five clips into Media Pool Bin 1, cut them into a timeline, then drag those five edited clips over into Media Pool Bin 2, the Bin 1 clips bear no inherent link to the Bin 2 clips. What this entails is that selecting the clips you first imported in Bin 1 and picking Unlink Selected Clips will also unlink the instances of those clips you cut into the timeline, yet the duplicate clips you produced by dragging the timeline clips over into Bin 2 stay entirely untouched.

### Summary of Methods for Conforming and Relinking

Owing to timelines and clips being handled apart from one another, you have several avenues for reconforming a timeline's clips to clips in the Media Pool, and clips at large to a project's matching source media on disk. Exactly which avenues prove most useful rests wholly on the workflow you've adopted.

- Conforming clips during XML and AAF import: Bringing in a project by way of AAF or XML offers you the choice of leaning on the file paths baked into the AAF or XML file to pull every referenced media item into the Media Pool for automatic reconforming to the imported timeline's clips. Should the media have shifted so the file paths no longer resolve, you'll be asked to locate the media during import. You're also free to disregard the AAF or XML file's embedded file paths and instead bring in a separate batch of media files at another location (possibly even in a wholly different media format) whose file names and timecode match the clips in the AAF or XML file you're importing.
- Importing clips before importing an EDL, AAF, or XML: For EDL workflows, the media an EDL will conform against has to enter the Media Pool ahead of importing the EDL. That said, you're free to do likewise for AAF and XML import workflows. Once clips are brought into the Media Pool ahead of an AAF or XML import, DaVinci Resolve can automatically reconform the imported timeline's clips to the Media Pool ones first, then afterward go hunting on disk for media matching clips that couldn't be located in the Media Pool. How this plays out hinges on whichever options you've chosen within the Import AAF/EDL/XML dialog.
- Conform missing clips by importing their source media into the Media Pool: Provided the "Automatically conform missing clips added to Media Pool" setting stays on within the General Options panel of the Project Settings, DaVinci Resolve will keep trying to refresh the conformed bond between clips you're feeding into the Media Pool and whatever missing clips sit across your project's various timelines. This behavior fires off any time you feed clips into the Media Pool by importing, by copying and pasting, or by spawning duplicates of clips. To give an example, if a timeline clip reads as missing for lack of any matching Media Pool clip, merely bringing a clip whose file name and timecode line up into the Media Pool will reconform the missing timeline clip on its own, with nothing further required of you. Do keep in mind that the "Auto conform clips with media added into Media Pool" setting needs to stay off wherever collaborative workflow is involved.
- Using the Import Additional Clips commands: Importing media solely for a timeline's missing clips can be made automatic by right-clicking that timeline within the Media Pool and reaching, from the contextual menu, for the Timelines > Import > Additional Clips With Loose (or Tight) Filename Match commands. On their own these sweep your file system's chosen directory tree for media that matches every offline clip in that timeline. The "Loose Filename Match" command disregards file extensions (which lets you conform to substitute media formats), while the "Tight Filename Match" command insists that file extensions agree.
- Reconform online clips by importing new media into the Media Pool: Provided the "Automatically conform missing clips added to Media Pool" setting stays on within the General Options panel of the Project Settings, DaVinci Resolve will keep trying to refresh the conformed bond between clips you're feeding into the Media Pool and any clips across your project's various timelines whose Conform Lock Enabled setting is switched off. This behavior fires off any time you feed clips into the Media Pool by importing clips, by copying and pasting clips, or by spawning duplicates of clips.

By default, every clip belonging to an imported timeline, or one you've cut into a freshly created timeline, has Conform Lock Enabled switched on by default (barring the source media going missing). Conform Lock Enabled merely signifies that a given timeline clip is configured to regard only the source clip in the Media Pool it's presently conformed to as the right match; all other Media Pool clips get disregarded, even where several clips share a file name and overlapping timecode that would otherwise qualify them as valid matches too (as happens when you hold several copies of one clip in differing formats, or several VFX clip versions sharing a name and timecode). Right-clicking a timeline clip that has several candidate matches in the Media Pool and switching Conform Lock Enabled off will make that clip surface a "clip conflict" error, accompanied by an attention badge sitting left of its name in the timeline. Double-clicking that badge brings up a dialog presenting every Media Pool clip whose file name or reel name matches and whose timecode overlaps, letting you settle on which Media Pool clip to conform that timeline clip against. NOTE: Whenever collaborative workflow applies, the "Auto conform clips with media added into Media Pool" setting has to remain turned off.

- Using Conform Lock commands to make a given timeline clip bind itself onto a particular Media Pool clip: A by-hand command that conforms one chosen timeline clip to one chosen Media Pool clip. Handy whenever, for any reason, none of the automatic conforming approaches pan out.
- Using the Relink command on clips or bins in the Media Pool: When a DaVinci Resolve project holds unlinked clips within the Media Pool, that signals the tie between those clips and their matching source media files on disk has been broken. Here any of three commands — Relink Media, Relink Selected Clips, or Relink Clips in Selected Bins — will tie clips back to their matching source media wherever that storage volume happens to sit. As part of this, every instance of those clips across all the project timelines they appear in gets relinked automatically. You can confine the relink to unlinked clips alone by picking them out specifically, yet you may equally relink clips that are already linked should you wish to force-relink them onto different media files (Relink Clips in Selected Bins relinks unlinked and linked clips together in one pass). The Relink command sweeps every subdirectory beneath the directory you've currently chosen on its own, which comes in handy when relinking to media that's been shifted elsewhere and may now sit within a different directory layout. A caution, though, regarding sweeping large SAN volumes – it's unwise to point this command at a starting directory too far up the file path, since the resulting searches can drag on far longer than expected.
- Using the Change Source Folder command: There's also the option of relinking offline Media Pool clips through the Change Source Folder command, which rewrites the directory layout within each chosen clip's file path into a fresh file path rooted at a parent directory you nominate. This proves chiefly handy when relinking clips to media you've relocated, provided that media keeps the same subdirectory layout it carried when first imported. On that account, it's a quick and safe command to reach for when relinking to an organized body of media on a SAN volume.
- Using the Reconform From Bin(s) command: Should you have brought several versions of the same clips, sharing file names, overlapping timecode, or other matching traits, into distinct bins of the Media Pool, you can switch off Conform Lock Enabled for every clip in the timeline you mean to reconform, then call on the Reconform From Bin(s) command to reconform those timeline clips against Media Pool clips inside one or more bins you nominate. Reconform From Bin(s) further lets you settle on the precise conform criteria used to match timeline clips against the clips in the chosen bins. One notable trait of this command is that DaVinci Resolve reconforms only those timeline clips it can match to media within the bins you've picked; any timeline clip for which no match turns up stays exactly as it was before you ran the command.
- Using the Reconform From Media Storage command: Through it, timeline clips can be reconformed against clips held inside a chosen file-system directory that hasn't first been brought into the Media Pool, and likewise lets you settle on the precise conform criteria used to match timeline clips against the clips in the chosen bins. One notable trait of this command is that DaVinci Resolve reconforms only those timeline clips it can match to media inside the directory structure you've picked; any timeline clip for which no match turns up stays exactly as it was before you ran the command.
- Overwriting on-disk clips that a DaVinci Resolve project already links to: Finally, and by no means least, DaVinci Resolve has the sense to relink Media Pool clips on its own once they've been overwritten on disk by another version of the same file, as long as the file name, timecode, and reel name (where used) in the file's new version still agree.

Each of these approaches to conforming and relinking media gets a closer, more detailed walkthrough in the sections ahead.

### Conform Multiple Selected Timelines

Several timelines can be conformed from the same source media all at once. Within the Media Pool, mark the timelines you mean to conform by holding Option or Shift as you click each. Then right-click any one of those highlighted timelines and choose Timelines Reconform from Bins or Reconform from Media Storage.

### Unlinking Clips

You're also free to unlink clips inside the Media Pool. To go about it, pick the clip or clips you wish to unlink, right-click one of those selected clips, and choose Unlink Selected Clips from the contextual menu.
