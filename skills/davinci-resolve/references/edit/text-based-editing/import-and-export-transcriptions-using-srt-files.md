### Import and Export Transcriptions using SRT Files

Standard .srt files let you move transcription text in and out. To Import a Transcription using an SRT File: For correct results, the clip you’re adding subtitles to must share its timecode with the timecode stored in the .srt file. 1 In the Transcription window, open the Option menu and pick Import Subtitles from the dropdown menu. 2 Find the .srt subtitle file through your file browser and click Open. 3 In the Media Pool, click the Transcribe icon so the Transcription window opens, where the subtitles can be reviewed and edited. Here is how to Export a Transcription using an SRT File: 1 In the Transcription window, open the Option menu and choose the Export Subtitles entry. 2 At this point the Export Subtitles dialog appears. 3 Provide a file output name plus a path where the .srt file should be saved. 4 4As needed, complete the following subtitle fields: Caption Preset, then Maximum Characters per Line, plus Number of Lines, along with Gap Between Subtitles. 5 Press the Create button to write out the .srt file.

The Export Subtitles dialog box accessed from the Transcription window’s Option menu.
