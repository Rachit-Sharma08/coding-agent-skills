### Preparing Clips for Editing and Viewer Playback

Ahead of any cutting, many tasks help you get footage ready. This chapter walks you through browsing, picking, and playing back the material you need to log — placing markers, marking In and Out points, and building subclips as you spot the pieces you intend to use further along in your edit.

### Viewer and logging keyboard shortcuts

Default shortcuts use the manual’s macOS modifier names.

| Shortcut | Action |
| --- | --- |
| Arrow keys in Media Pool | Move selection; left/right also open or close bins |
| Shift-click | Select a contiguous range |
| Command-click | Select nonadjacent clips |
| Command-A | Select all clips in the Media Pool browser |
| Return or Enter | Open the selected clip or timeline in the viewer |
| I; O | Set In; set Out in the Media Pool, Source Viewer, or Timeline |
| Option-Shift-I; Option-Shift-O | Set video-only In; Out |
| Command-Shift-I; Command-Shift-O | Set audio-only In; Out |
| Shift-I; Shift-O | Go to In; Out |
| Spacebar | Play or stop |
| J; K; L | Reverse; stop; forward playback |
| Option-L | Play again |
| Option-K | Stop and return to the prior playhead position |
| / | Play around the selection |
| Up; Down | Previous; next clip or edit |
| M | Add a marker without stopping |
| Command-M | Pause, add/edit a marker, then resume |
| Shift-M | Modify marker |
| Option-M | Delete marker |
| Shift-Up; Shift-Down | Previous; next marker |
| Option-B | Create a subclip in the selected Media Pool bin |
