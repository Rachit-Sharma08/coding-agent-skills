### Editing keyboard shortcuts

Default shortcuts use the manual’s macOS modifier names. Edit commands take clips from the Media Pool or Source Viewer into the Timeline.

| Shortcut | Action |
| --- | --- |
| V | Select the nearest edit |
| Shift-V | Select the clip at the playhead |
| U | Cycle incoming, outgoing, and centered edit selection |
| Option-U | Cycle audio/video selection |
| Option-Y | Select forward clips on all tracks |
| Command-Option-Y | Select backward clips on all tracks |
| Y | Select forward clips on the current track |
| Command-Y | Select backward clips on the current track |
| Up; Down | Previous; next edit or clip |
| Delete | Lift clip, leaving a gap |
| Forward Delete | Ripple delete and close the gap |
| Command-Backslash | Cut clips at the playhead |
| N | Toggle snapping |
| Command-Shift-L | Toggle linked selection |
| Option-1 through 8 | Set video destination; repeat to enable/disable |
| Command-Option-1 through 8 | Set audio destination; repeat to enable/disable |
| Option-Shift-1 through 8 | Toggle individual video track locks |
| Option-Shift-9 | Toggle all video track locks |
| Option-Shift-F1 through F8 | Toggle individual audio track locks |
| Option-Shift-F9 | Toggle all audio track locks |
| F9 | Insert |
| F10 | Overwrite |
| F11 | Replace with the first selected clip |
| F12 | Place on Top |
| Shift-F10 | Ripple Overwrite |
| Shift-F11 | Fit to Fill |
| Shift-F12 | Append to End |
| Command-Z | Undo |
| Command-Shift-Z | Redo |
