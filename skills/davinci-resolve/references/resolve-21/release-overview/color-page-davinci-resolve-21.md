### Introduction

With version 21, DaVinci Resolve debuts a Photo page that gives both colorists and photographers access to Hollywood’s leading color tools when working on still images. From this Photo page you can bring in and organize your photographs, and it ties into the color page so grading happens through a node based workflow. Across a whole project you’re able to shape color expressively using primary color correction, curves, qualifiers, power windows and node editor. On top of that, a DaVinci color panel lets you tweak several parameters simultaneously. The release also brings fresh AI capabilities: IntelliSearch speeds up content searching, CineFocus handles focal point adjustment, and additional features refine faces. More than 70 fresh graphics arrive in Fusion via the Krokodove toolset, Fairlight folders make audio track management simpler, and you’ll notice refinements to keyframing, MultiMaster trim passes, and layer list node graphs. This new features guide walks you through all of it, and once the public beta wraps it will be folded into the DaVinci Resolve reference manual. Enjoy what’s new in DaVinci Resolve 21.
