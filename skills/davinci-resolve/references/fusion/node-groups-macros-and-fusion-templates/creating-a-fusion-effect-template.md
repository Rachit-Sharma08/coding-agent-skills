### Creating a Fusion Effect Template


Building a Fusion Effect template begins by pulling a clip out of the Edit page Timeline and into Fusion. That clip serves only to build the template and won't be stored along with the effect. After you're in Fusion, you reach for Fusion's nodes to assemble whatever effect you have in mind. Whether the job calls for one node or a hundred depends entirely on the effect you're after. As an example, Fusion's Color Correction nodes let you put together a basic color corrector ready for use on the Edit page.

.Putting together a basic Color Corrector effect goes as follows: 1 Drop the Color Corrector node in between the MediaIn and MediaOut nodes. 2 Click the Color Corrector node within the Node Editor, then hit Cmd-A to grab the rest of the nodes too. 3 Right-click on any of the highlighted nodes and pick Macro > Create Macros off the contextual menu. Whichever checkboxes you tick in this window decide which parameters turn up in the Edit page Inspector. 4 Up comes the Macro Editor window. From here, tick the checkboxes for whatever parameters you'd like surfaced in the Edit page Inspector. 5 Type your effect's name across the top of the Macro Editor window. 6 Saving the Macro means clicking Close at the window's foot, then clicking Yes when a dialog pops up asking you to keep the changes. For DaVinci Resolve to treat a Macro as an effect, it has to be saved into the right folder. Within the save dialog, store the Macro at these locations: On macOS: `Macintosh HD/Users/username/Library/Application Support/Blackmagic Design/ DaVinci Resolve/Fusion/Templates/Edit/Effects` On Windows: `C:\Users\username\AppData\Roaming\Blackmagic Design\DaVinci Resolve\ Support\Fusion\Templates\Edit\Effects` On Linux: `home/username/.local/share/DaVinciResolve/Fusion/Templates/Edit/Effects` Your Fusion Effects can be tucked away and organized into individual subfolders beneath those paths. Such subfolders then surface within the Effects section over on the Edit page. Before the effect shows up in the Edit page Effects Library, though, you'll have to close DaVinci Resolve and start the application back up.

Creating a Fusion Effect Template for Two or More Layers When the effect you're after calls for several images, as a video wall does, begin by making a Fusion clip on the Edit page Timeline holding as many layers as you want the effect to carry. Those clips exist purely to set up the right count of image inputs for the template and won't be kept with the effect. After you're in Fusion, draw on Fusion's nodes to build the effect you envision. Save the Macro by walking through the very same steps used for single clip effects. Switch on whatever parameters you mean to control over on the Edit page. So that the order of video layers inside the effect can be swapped, confirm the Layer checkbox is on for every MediaIn node. With the Macro saved and DaVinci Resolve relaunched, applying the effect across multiple timeline layers requires that you build a Fusion clip. That Fusion clip ought to hold the same layer count the effect demands. Reading the Timeline layers from the bottom track upward, their order lines up with the MediaIn numbers. So MediaIn1 takes the placement and look of video track 1 while MediaIn2 corresponds to video track 2 and the pattern continues from there. Should you wish to remap which tracks feed which MediaIn nodes, adjust the Layer number in the Inspector, provided you'd switched on the MediaIn Layer checkbox back when you made the Macro.
