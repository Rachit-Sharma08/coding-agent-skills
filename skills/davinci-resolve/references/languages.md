# Reference Language Selection

Open when you need a language version of this skill's references other than English.

Choose an explicit reference-language preference first, otherwise the request language, then English as the default fallback. Response language is independent of reference language.

Only English references are bundled. Disclose a missing requested translation and use the [English reference index](INDEX.md), retaining the requested response language. Do not invent translated paths; preserve control names, identifiers, units, version limits, and examples.
