## Playback

### Playback

Use Optimized Media if Available – Page 200 Flips between using Optimized Media or the original media. Proxy Handling – Page 212 Surfaces a submenu governing how proxy media playback runs. Timeline Proxy Resolution – Page 199 Choices covering Timeline Proxy Mode playback. Render Cache – Page 201 Choices covering use of the Render Cache. Delete Render Cache – Page 209 Choices covering deletion of the Render Cache. Manage Render Cache – Page 210 Brings up the Cache Manager. Fusion Memory Cache – Page 1258 Choices covering use of the Fusion Cache. Play Reverse – Page 739 Runs playback 100% in reverse. Stop – Page 868 Halts playback. Play Forward – Page 739 Runs playback 100% ahead. Pause/Start Playback – Page 739 Halts and resumes playback. Play Again – Page 739 Kicks playback off again from the original position. Playback Post-Roll – Page 699 Keeps the playhead running on beyond the timeline's final clip. Stop and Go to Last Position – Page 745 Sends the playhead back to its original spot upon stopping.

Record – Page 3767 Kicks off recording within the Fairlight Page. Fast Reverse – Page 3692 Runs playback in Fast Reverse. Fast Forward – Page 3692 Runs playback in Fast Forward. Play Slow – Page 740 Runs forward playback in Slow Motion. Fast Review – Page 691 Kicks off the Fast Review function. Loop/Unloop – Page 741 Flips Looping playback on or off. Play Around/To – Page 741 Choices for picking the Play Around/To mode. Timecode – Page 747 Choices for stepping timecode up or down. Go To – Page 752 Choices for sending the playhead straight to a given location. Step One – Page 739 Steps ahead or back by one frame or one second. Previous Sends the playhead to the prior Clip, Keyframe, Marker or Gap. Next Sends the playhead to the following Clip, Keyframe, Marker or Gap. Jump Left – Page 3771 Shifts clip selection leftward within the Fairlight page. Jump Right – Page 3771 Shifts clip selection rightward within the Fairlight page. Cintel Scanner – Page 485 Transport controls covering the Cintel Scanner.
