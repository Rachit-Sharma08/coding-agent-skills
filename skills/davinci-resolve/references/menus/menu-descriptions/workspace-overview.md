## Workspace

### Workspace

Switch to Page – Page 21 Jumps to the page you choose. Show Page – Page 16 Reveals or conceals particular pages. Show Page Navigation – Page 22 Turns off the page navigation icons in the GUI. Show Panel in Workspace – Page 59 Reveals or conceals particular panels. Active Panel Selection – Page 57 Jumps to the panel you choose. Media Pool Windows – Page 402 Shows a roster of the open Bin windows. Dual Screen – Page 61 Puts the DaVinci Resolve interface into Dual Screen Layout. Primary Display – Page 62 Lets you pick which monitor drives the primary DaVinci Resolve display. Video Clean Feed – Page 63 Sends the finished video output to the screen you choose. Viewer Mode – Page 3020 Selects the Viewer Mode. Fairlight Viewer – Page 4009 Selects the Fairlight Viewer mode. Single Viewer Mode – Page 684 Switches Single Viewer mode on or off in the Edit Page. Stream to visionOS – Page 4267 Stores and recalls custom screen layouts. Layout Presets – Page 63 Stores and recalls custom screen layouts. Reset UI Layout – Page 63 Returns the UI Layout to its default state. Background Activity – Page 4057 Shows how far along a render's upload is.

Data Burn-In – Page 303 Brings up the Data Burn-In window. Gallery – Page 3283 Brings up the Gallery Window inside the Color Page. Keyword Manager – Page 355 Brings up the Keyword Dictionary. People – Page 423 Brings up the People window for face detection. Scene Cut Detector – Page 469 Brings up the legacy Scene Detector within the Media page. Timecode Window – Page 704 Brings up the floating timecode window. Video Scopes – Page 3033 Brings up the Scopes window. Remote Grading – Page 4211 Establishes a connection from the Color page out to a Remote Grading client. Remote Monitoring – Page 4212 Lets the viewer output be watched from a remote location. Remote Rendering – Page 4083 Designates the machine as a rendering workstation. Monitor Calibration – Page 3023 Brings up the Monitor Calibration tools. Console – Page 1560 Shows the Console Window used for diagnostics and Fusion Scripts. Scripts Refer to the Workspace > Documentation menu for scripting details. Workflow Integrations – Page 4270 Picks an installed Workflow Integration Plugin.
