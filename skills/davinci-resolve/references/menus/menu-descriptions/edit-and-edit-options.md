## Edit

### Edit

Undo – Page 73 Reverses the prior change. Redo – Page 73 Reapplies the prior change. History – Page 73 Brings up the Undo History submenu. Cut – Page 824 Runs a cut on whatever is currently selected. Ripple Cut – Page 824 Runs a ripple cut against the current selection. Cut Head – Page 3825 Trims the clip rearward from the playhead within the Fairlight page. Cut Tail – Page 3825 Trims the clip forward from the playhead within the Fairlight page. Copy – Page 824 Runs a copy on whatever is currently selected. Copy Head – Page 3825 Duplicates the clip rearward from the playhead within the Fairlight page. Copy Tail – Page 3825 Duplicates the clip forward from the playhead within the Fairlight page. Paste – Page 824 Drops in the selection copied or cut earlier. Paste Insert – Page 824 Drops a clip in as an insert edit. Paste Attributes – Page 1034 Drops in video and audio attributes. Paste Value – Page 3313 Drops the value of one particular parameter across Color nodes. Remove Attributes – Page 1035 Strips off audio and video attributes. Dolby Vision® – Page 259 Copies and pastes Trim metadata where Dolby Vision is concerned. Duplicate Clip or Current Timeline – Page 401 Produces a copy of whichever clip or timeline is current. Duplicate Selection – Page 3821 Clones one or more chosen clips within Fairlight. Delete Selected Runs a delete across every selected item. Ripple Delete – Page 782 Runs a ripple delete against the chosen clip.

Delete Gaps – Page 785 Clears out gaps within the active timeline. Select All Runs a Select All across the active panel. Deselect All Drops whatever selections sit in the active panel. Select – Page 760 Surfaces a submenu for grabbing neighbouring clips along a timeline. Insert – Page 852 Carries out an Insert Edit with the chosen clip. Overwrite – Page 851 Carries out an Overwrite Edit with the chosen clip. Replace – Page 853 Carries out a Replace Edit with the chosen clip. Place on Top – Page 573 Carries out a Place on Top Edit with the chosen clip. Ripple Overwrite – Page 572 Carries out a Ripple Overwrite Edit with the chosen clip. Fit to Fill – Page 836 Carries out a Fit to Fill Edit with the chosen clip. Append to End of Timeline – Page 861 Tacks the chosen clip onto the timeline's tail. Multicam – Page 908 Surfaces the Multicam editing controls. Insert Gap – Page 784 Surfaces the Multicam editing controls. Swap Clips Towards Left – Page 819 Trades the chosen clips for whichever clip sits left of the selection. Swap Clips Towards Right – Page 819 Trades the chosen clips for whichever clip sits right of the selection.

### Edit Options

- Switch to Timeline After Edit – Page 836

Shifts focus onto the timeline on its own once an edit lands, in place of the Source Viewer.

- Decompose Compound Clips on Edit – Page 927 Breaks apart nested clips on timelines by itself to ease editing.
- Automatically Create Tracks on Edit – Page 768 Spins up fresh tracks on its own should your source carry more tracks than the timeline holds.
