### Timeline

Track Lock Blocks any more changes to the chosen track. Sync Lock – Page 948 Picks tracks for editing operations on its own. Enable/Disable Video Tracks – Page 3050 Reveals or conceals particular video tracks. Output Blanking – Page 300 Configures letterboxing options.

New Compound Clip – Page 923 Builds a compound clip from the chosen clips. New Fusion Clip – Page 1288 Builds a Fusion composition from the chosen clips. New VFX Connect Clip – Page 1143 Ties the current selection to the standalone Fusion build. Open in Timeline – Page 929 Unfolds a nested timeline briefly into its component pieces for editing. Decompose in Place – Page 927 Splits a nested timeline back into its original component pieces. Split PSD Layers in Place – Page 829 Splits a photoshop document back into its original component layers. Enable/Disable Clip – Page 760 Flips a clip’s visibility on or off. Link Clips – Page 789 Flips Link or Unlink for the chosen clips. Change Clip Duration – Page 567 Brings up the Change Clip Duration tools. Clip Speed – Page 1092 Brings up the simple speed retiming controls. Fusion Referenced Compositions – Page 1290 An assortment of selection tools covering Fusion Reference Compositions. Auto Align Clips – Page 826 Lines up clips along a timeline according to timecode or audio waveform.

### AI Tools

- Dialogue Matcher – Page 3829

Matches dialog sound across two clips for you.

- Voice Convert – Page 3841 Turns one voice into another by way of AI.

Load Current Timeline into Source Viewer – Page 727 Brings the chosen timeline across into the source viewer so it can be edited in tabs. Find Current Timeline in Media Pool – Page 409 Brings up the media pool bin holding the chosen timeline and spotlights it.

### Audio Operations

- Trim Audio Levels – Page 3864

Offers choices to raise or lower a clip's level by 1 or 3dB.

- Ripple Delete Silence Hunts down silences, removes them, and ripple deletes them
- EQ Matcher – Page 3827 Matches EQ sound across two clips for you.
- Level Matcher – Page 3828 Matches levels across two clips for you.

Take Selector – Page 922 Builds a Take Selector out of the chosen clips. Finalize Take – Page 667 Drops a Take Selector and keeps the starred take. Multicam Cut – Page 916 Cuts across to a different angle within a Multicam Clip. Multicam Switch – Page 916 Shifts to a different angle within a Multicam Clip without making a cut. Render Cache – Page 201 Flips the options governing how Fusion compositions cache within a timeline. Conform Lock Enabled – Page 1179 Pins clip references onto one media file so accidental changes can't happen. Conform Lock with Media Pool Clip – Page 1179 Compels a clip to point at one media file chosen in the Media Pool. Find Clip in Media Pool – Page 905 Tracks down the chosen clip within the Media Pool. Match Frame to Source Clip – Page 903 Runs a Match Frame operation against the chosen clip in the timeline.
