## Fairlight

### Fairlight

Bus Format – Page 3752 Brings up the Bus Format window, where mono through multi-channel Atmos buses can be built. Bus Assign – Page 3755 Brings up the Bus Assign window, used to route tracks to buses, buses onto tracks, and one bus into another. Presets Library – Page 667 Brings up the Presets Library, from which saved Preset Configurations are picked; the available kinds are EQ, then Dynamics, then Plugins, alongside Global Track, Global Bus, plus Fairlight Configurations. Link Group – Page 3750 Brings up the Link Group window for linking groups of tracks together. VCA Assign – Page 3904 Brings up the VCA Assign window for assigning VCA groups onto particular tracks. Patch Input/Output – Page 3757 Brings up the Patch Input/Output window for patching Source-to-Destination routings. Test Tones Settings – Page 3735 Brings up the Test Tones Settings window, whose Oscillator generates a range of signal tones. Synchronization Settings – Page 3736 Brings up the synchronization timecode settings within the Fairlight page. Input Monitor Style – Page 3779 Lets you pick the way an input is monitored.

Monitoring – Page 3997 Lets you switch the Global monitoring among Mute, Dim, and Mono. Exclusive Solo – Page 3907 Once active, drops every other soloed track out of solo. Immersive Audio Reveals the immersive audio tools below.

- B-Chain Control – Page 4031
- Space View Scope – Page 4035
- Import Master - import ADM files – Page 4015
- Export Master - export ADM files – Page 4015
- Renderer Settings – Page 4015

Automation – Page 3915 Enumerates the Fairlight automation choices. Batch Fade Settings – Page 3833 Brings up the Batch Fade Settings window for setting fade types and durations. Apply Batch Fades – Page 3833 Lays down the fades configured in the Batch Fade Settings window. View Clip Info Display – Page 3706 Brings up the Clip Info Display window. Show Clip Gain Line – Page 3863 Reveals or conceals the Clip Gain Line on timeline clips.
