## View

### View

Bypass Color and Fusion – Page 684 Switches Color and/or Fusion operations within a timeline on or off. Display Broadcast Safe Exceptions – Page 2975 Switches on the Broadcast Safe overlay. Source/Timeline Viewer – Page 836 Flips which of the Source or Timeline viewer is active on the Edit page. Source Clip/Source Tape – Page 553 Flips between Source Clip and Source Tape within the Cut page viewer. Toggle Source Timeline – Page 760 Flips the Source Timeline on or off. Zoom Zoom choices for the viewer. Zoom Around Mouse Pointer – Page 723 Anchors the timeline zoom on the pointer instead of the playhead on the Edit page. Zoom Audio Waveform – Page 3696 Configures waveform zooming parameters within the Fairlight page. Safe Area – Page 555 Flips and picks the safe area overlays across the Edit and Color pages. Rulers – Page 742 Switch on and lay out rulers Guides – Page 743 Switch on and lay out guides Switch Eye To – Page 338 Picks the current eye for Stereoscopic workflows. Viewer Overlay – Page 1088 Configures the Viewer On Screen controls within the Edit Page. Show Duplicate Frames – Page 728 Flags duplicate clips across the Edit page timeline.

Show File Names – Page 454 Flips between showing Clip names or File names on the Edit page. Overlay Synced Audio File Names – Page 453 Surfaces the original audio files' names on the Edit page. Show Audio Track Layers – Page 3797 Exposes track layers within the Fairlight page. Show Subtitle Regions – Page 1120 Reveals or conceals regions across the subtitle tracks. Timeline Thumbnail Mode – Page 3055 Flips clip order across A or C mode within the Color page. Timeline Thumbnail Info – Page 3052 Decide which clip info rides on the thumbnail within the Color page. Timeline Thumbnail Size – Page 3049 Picks how large the thumbnails run within the Color page. Show Current Clip With Handles – Page 3052 Surfaces a clip's handles within the Color page. Show Markers – Page 895 Reveals or conceals markers according to color. Show Flags – Page 883 Reveals or conceals flags according to color. Timeline Scrolling – Page 3702 Configures how the timeline scrolls within the Fairlight page. Show Preview Marks – Page 842 Flips Preview Marks on or off on the Edit page. Enable Multiview Edit Preview – Page 940 Switches the multi-frame displays on or off within the Edit page.
