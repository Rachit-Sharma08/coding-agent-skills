## Trim

### Trim

Normal Edit Mode – Page 814 Drops the timeline into Selection Mode. Trim Mode – Page 934 Drops the timeline into Trim Mode. Range Selection Mode – Page 3797 Switches Fairlight over to Range Mode. Focus Mode – Page 3700 Drops the Fairlight timeline into focus Mode. Dynamic Trim mode – Page 964 Drops the timeline into Dynamic Trim Mode. Toggle Slip/Slide Mode – Page 964 Flips back and forth between slip and slide trim modes. Blade Edit Mode – Page 821 Flips the timeline over to blade mode. Trim Editor – Page 940 Switches on the Precision Trim Editor. Select Nearest – Page 945 Grabs an assortment of edit points nearest the playhead. Select All Clips Under Playhead – Page 771 Grabs every clip across every track beneath the playhead. Edit Point Type Cycles the currently chosen edit point through the outgoing, centered, or incoming portion of the edit Toggle V+A/V/A Cycles the Edit Point type above across video, audio, or combined video-and-audio selections. Select Nearest Edit To – Page 945 Grabs the closest edit point relative to an assortment of clip parameters. Select Nearest Clip To – Page 946 Grabs the closest clip relative to an assortment of clip parameters. Nudge Surfaces a menu for shifting the chosen clips one frame, or several frames, left or right. Trim Start – Page 962 Trims every clip crossing the playhead rearward from that spot. Trim End – Page 962 Trims every clip crossing the playhead forward from that spot.

Trim to Selection – Page 3690 Trims the clips' heads and tails down to the chosen range within the Fairlight page. Extend Edit – Page 964 Resizes one or more chosen edit points or clips. Extend Edit Selection To – Page 964 Surfaces a menu for grabbing prior and following tracks and edits feeding the Extend Edit function. Move Edit Selection To – Page 964 Surfaces a menu for stepping to prior and following tracks and edits feeding the Extend Edit function. Resize – Page 934 Alters the clip in/out points according to where the playhead sits. Ripple – Page 934 Alters the clip in/out points according to where the playhead sits, by way of a Ripple operation. Roll – Page 934 Alters the clip in/out points according to where the playhead sits, by way of a Roll operation. Slip Playhead To – Page 964 Slides the clip from the playhead's present spot over to the clip's in or out point. Fade In to Playhead – Page 1081 Builds a fade in running from the clip's start to where the playhead sits. Fade Out to Playhead – Page 1081 Builds a fade out running from the playhead's spot to the clip's end. Crossfade Selection Builds a crossfade across the chosen range within the Fairlight page. Slip Audio – Page 790 Surfaces a menu for slipping audio ahead and back at the frame or subframe level. Slip Eye – Page 452 Nudges the opposite eye one frame left or right within the Color Page’s Stereo 3D palette.
