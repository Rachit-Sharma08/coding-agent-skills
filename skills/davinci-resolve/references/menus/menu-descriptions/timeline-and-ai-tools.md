## Timeline

### Timeline

Add Transition – Page 1039 Drops the default transition onto the chosen edit point. Add Video Only Transition – Page 1039 Drops the default transition onto the chosen Video edit point alone. Add Audio Only Transition – Page 1039 Drops the default transition onto the chosen Audio edit point alone. Select Clips Hands you a way to grab a span of clips.

- Forward – Page 772 Grabs every clip ahead of the playhead on a lone track or across all tracks.
- Backward – Page 772 Grabs every clip behind the playhead on a lone track or across all tracks.
- By Flag Color – Page 773 Grabs every clip that was earlier flagged in a given color.
- By Marker Color – Page 773 Grabs every clip carrying markers of a given color.
- By Clip Color – Page 773 Grabs every clip of a given color.

Razor – Page 821 Switches on the Razor (Blade) tool. Split Clip – Page 813 Divides a clip where the playhead sits. Join Clip – Page 813 Merges two clips split apart by a through edit. Detect Scene Cuts – Page 468 Switches on Scene Cut Detection for the current selection.

### AI Tools

- Audio Assistant – Page 3911

Mixes your timeline audio for you.

- Create Subtitles from Audio – Page 1112 Builds subtitles on its own drawn from the speech across audio tracks.
- Record Voiceover – Page 984 Brings up the Record Voiceover tool.

### Audio

- Bounce Selected Tracks in Place – Page 3910

Bounces the chosen tracks onto a fresh layer within the Fairlight page.

- Bounce Mix to Track – Page 3910 Bounces the chosen mix onto a fresh track within the Fairlight page.
- Flatten Audio Track Layers – Page 3698 Collapses Track Layers within the Fairlight Page.
- Trim Audio Edits to Frame Boundaries – Page 983 Wipes out any sub-frame audio adjustments.
- Mute Selected Track – Page 1004 Silences the chosen audio track within the Fairlight Page.
- Clear Mutes – Page 3907 Restores sound to every track within the Fairlight Page
- Solo Selected Tracks – Page 969 Solos the chosen audio track within the Fairlight Page.
- Clear Solo – Page 3907 Lifts solo off every track within the Fairlight Page.
- Layered Audio Editing – Page 3830 Switches on Audio Layering within the Fairlight Page.
- Audio Scrubbing – Page 698 Flips audio scrubbing on or off.
- Loop Jog – Page 3769 Flips Loop Jog within the Fairlight Page.

### Video

- Clean Up Video Tracks – Page 834

Surfaces a toolset for tidying up how a timeline’s video tracks are organized.

- Switch to Camera Originals – Page 548 Flips between Camera Masters and ISO’s within ATEM projects.
- Linked Move Across Tracks – Page 787 Flips whether linked clips change tracks as one.
- Selection Follows Playhead – Page 697 Flips the auto-selection of whichever clip sits beneath the playhead.
- Ripple Timeline Markers – Page 889 Has Timeline markers reflow alongside ripple operations.

Match Frame – Page 903 Runs a Match Frame operation against the clip. Snapping Switches playhead snapping on and off. Linked Selection – Page 786 Flips linked selection of clips. Source Track Selector – Page 837 Picks particular tracks for editing operations. Auto Select – Page 903 Picks tracks for editing operations on its own.
