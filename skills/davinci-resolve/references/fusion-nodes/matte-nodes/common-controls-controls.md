### Common Matte settings Inspector

Settings Tab Every tool in the Matte category carries the Settings tab in the Inspector. These controls behave the same way and stay consistent from tool to tool. Blend The Blend control mixes the tool's original image input against whatever modified output image the tool finally produces. At a blend value of 0.0, the outgoing image matches the incoming one exactly. Normally this makes the tool bypass processing entirely, handing the input straight through to the output. Process When Blend Is 0.0 Even with the input value at zero, the tool still processes. This comes in handy when the node is scripted to set off another task while its value sits at 0.0.

Red/Green/Blue/Alpha Channel Selector Use these four buttons to confine the tool's effect to chosen color channels. Often this filter kicks in after the tool has already been processed. Take a Blur tool with the Red button deselected: the blur runs across the image first, then the red channel from the original input is laid back over the result's red channel. A few exceptions exist, such as tools where turning these channels off makes the tool skip that channel's processing outright. For those, a set of RGBA buttons lives on the tool's Controls tab. The buttons on the Settings and the Controls tabs are one and the same. Apply Mask Inverted Switching on the Apply Mask Inverted option flips the tool's entire mask channel. That mask channel is the merged outcome of every mask wired into or generated within a node. Multiply by Mask Choosing this option makes the masked image's RGB values get multiplied by the mask channel's values. As a result, every pixel of the image left out of the mask (that is, set to 0) turns black/transparent. Use Object/Use Material (Checkboxes) Certain 3D software can render to file formats carrying extra channels. The EXR file format notably supports Object ID and Material ID channels, which the effect can treat as a mask. These checkboxes decide whether those channels get used, when they're present. You pick which Material ID or Object ID is affected with the next batch of controls. Correct Edges This checkbox surfaces only when the Use Object or Use Material checkboxes are on. It switches the method for handling overlapping edges of objects within a multi-object image. With it on, the Coverage and Background Color channels serve to separate and refine the effect around the object's edge. Turn this option off (or supply no Coverage or Background Color channels) and aliasing can show up along the mask's edge. The Coverage and Background Color channels are covered in greater depth in the DaVinci Resolve Reference Manual at Chapter 78, "Understanding Image Channels" — the Fusion Reference Manual handles the same topic in Chapter 18. Object ID/Material ID (Sliders) Reach for these sliders to choose which ID builds a mask out of the image's object or material channels. Operate the Sample button just like the Color Picker: to lift IDs from the image shown in the view. Those channels must have been baked in when the image or sequence was rendered from a 3D software package.

Clipping Mode This setting governs how edges get treated while domain of definition rendering is taking place. It matters enormously when you blur the matte, since that may pull samples from areas of the image lying beyond the current domain.

- Frame: Frame is the default, and it has the node's domain of definition span the image's full frame automatically, effectively disregarding the current domain of definition. Should the upstream DoD fall short of the frame, whatever remains in the frame counts as black/transparent.
- Domain: Choosing Domain honors the upstream domain of definition while the node's effect is applied. Adverse clipping can result wherever the node relies on a large filter.
- None: Choosing None skips any source image clipping entirely. So any data the node's effect needs to process that would ordinarily sit beyond the upstream DoD counts as black/transparent.

Use GPU Three settings live on the Use GPU menu. Choosing Disable shuts off GPU hardware-accelerated rendering. Enabled puts the GPU hardware to work rendering the node. Auto draws on a capable GPU when one's around, and drops back to software rendering when no capable GPU is present Hide Incoming Connections Switching on this checkbox can conceal connection lines coming from upstream nodes, leaving a node tree looking tidier and more legible. With it on, the Inspector shows empty fields for each input on a node. Drag a connected node out of the node tree and into the field to hide that incoming connection line, as long as the node stays unselected in the node tree. Select the node in the node tree and the line comes back. Comments Use the Comments field to attach notes to a tool. Click the empty field and enter your text. Once a note is on a tool, a small red square shows up in the lower-left corner of the node while the full tile is displayed, or a tiny text bubble icon shows up on the right when nodes are collapsed. To view the note in the Node Editor, rest the mouse pointer over the node so the tooltip appears. Scripts Each tool in Fusion carries three Scripting fields on the Settings tab. Every one holds an edit box for entering scripts that run while the tool renders. For more details on scripting nodes, please consult the Fusion scripting documentation.
