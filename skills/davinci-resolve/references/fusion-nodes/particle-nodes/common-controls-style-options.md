### Style Options

Several of the options below show up on only certain styles, noted in each case. Apply Mode (Point and Point Cluster) Only 2D particles respond to this control; particle systems built in 3D are left untouched.

- Add: Where particles overlap, their individual color values are summed together to combine them.
- Merge: Where particles overlap, they are merged.

Sub Pixel Rendered (Point and Point Cluster) Whether the point particles render at Sub Pixel precision is decided by this checkbox; enabling it yields smoother motion but softer particles that cost a bit more render time. Number of Points and Variance (Point Cluster) How many points each Point Cluster holds is set by the value of this control. Animate (Bitmap Style) When the Bitmap source happens to be a movie file or an image sequence, this menu picks which frame is pulled from the source and assigned to particles as they spawn.

- Over Time: Every particle displays the image emitted by the Style Bitmap node at the present moment, and as time advances they all march to each next image together in lockstep. A particle born on frame 1 carries the Style Bitmap's frame 1 image. By frame 2, that original particle switches to the image from frame 2, as do any newly spawned particles. Every particle created always shares one and the same bitmap image drawn from their source.
- Particle Age: Working independently from its neighbors, each particle steps through the image sequence supplied by the Style Bitmap node. Put differently, a single particle's look is sampled from the Style Bitmap node at consecutive moments, keyed to how old it is.
- Particle Birth Time: A new particle grabs the image from the Style Bitmap node at the present moment and holds it fixed right up until that particle dies. As a result, every particle spawned on one frame ends up identical and remains so.

Time Offset (Bitmap Style) With this control the Bitmap source frame can be shifted in time relative to the present frame. Time Scale (Bitmap Style) The time span of the source bitmap images is scaled by a chosen factor through this control. To illustrate, a scale of 2 forces the particle spawned at frame 1 to sample the bitmap source over at frame 2. Gain (Bitmap and Brush Style) A gain correction is applied by this control to the image serving as the bitmap. Raising the value brightens the image, while lowering it pulls down the image's transparency together with its brightness. Style Bitmap (Bitmap Style) Selecting the Bitmap style brings up this control, paired with an orange Style Bitmap input on the node's icon over in the Node view. Wire a 2D node into this input so the particles receive images. There are a few ways to set this up: work directly in the Node view; alternatively, drag an image source node and drop it onto the Style Bitmap control out of the Node Editor or Timeline; or, as a third route, right-click the control and pick whichever source you want via the Connect To menu. Brush (Brush Style) The names of whatever image files sit in the Brushes directory show up in this menu. Where the Brushes directory lives is set within the Preferences dialog, under Path Maps. By default it is the Brushes subdirectory inside Fusion's install folder. Should the directory hold no images, the menu offers only None and no particles render. Noise (Blob Style) Raising the value of this control adds grain-style noise onto the blobby particle. Fade (Line Style) Falloff across the line particle's length is governed by the Fade control. At its default of 1.0, the line tapers off to nothing by the time it reaches the end of the length.

### Color Controls

What the Color Controls do is pick the color along with the Alpha values for particles spawned by the emitter. Color Variance These range controls give you a way to widen the spread of colors generated by the pEmitter. Putting the Red variance range at -0.2 to +0.2 yields colors deviating 20% to either side of the red channel, summing to a 40% total variance. Suppose the pEmitter is told to emit R0.5, G0.5, B0.5 (pure gray); the variance just described will yield points whose color spans from R0.3, G0.5, B0.5 up to R0.7, G0.5, B0.5. If you'd rather see color space as numbers running 0-256 or 0-65535, alter the figures Fusion uses through the Show Color As option found on the General tab inside the Preferences dialog.

### Lock Color Variance

The particles' color variance is locked by this checkbox. Unlock it and the color variance may be applied independently per color channel, opening up a wider palette of colors.

### Particles Color Over Life controls

Color Over Life Through this standard gradient control you choose a span of color values that the particle follows across its lifetime. The gradient's leftmost point stands for the particle's color when it is born. Its rightmost point gives the particle's color as its life ends. You can drop extra points onto the gradient control so the particle color shifts repeatedly through its life. Such a control comes in handy for fire-like effects (say, a flame that begins blue, turns orange, and finishes a deeper red). You can animate the gradient itself across time by right-clicking the control and picking Animate from the contextual menu. A single Color Over Life spline drives every point on the gradient, dictating how quickly the gradient itself transforms. There is also the From Image modifier you can apply, which builds a gradient out of the colors found in an image along a line drawn between two points.
