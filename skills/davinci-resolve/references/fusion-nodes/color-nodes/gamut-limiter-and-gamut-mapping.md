### Inputs

There are two inputs on the Gamut Limiter node, namely the input plus the effect mask. Input: The orange input carries the main 2D image used for the auto gain. Effect Mask: The blue input takes a mask shape generated by polylines, simple primitive shapes, paint strokes, or bitmaps coming from other tools. Wiring a mask here confines the change to only the pixels falling inside that mask. The effect mask gets applied once the tool itself has finished processing.

### Gamut Mapping controls

### Controls Tab

Only the primary controls required for tuning the Gamut Limiter parameters live in the Controls tab. Gamma Through a pop-up menu you indicate the type of gamma the clip is meant to carry, so set it to whatever fits that picture (this might align with the Timeline Color Space, though that hinges on how you're working). Tone Mapping Method Enables tone mapping to handle workflows where one color space must be transformed into another carrying a far bigger or far smaller dynamic range, by automating a stretch or squeeze of image contrast in a manner that yields a pleasing outcome without clipping.

- None: This setting turns off Input DRT Tone Mapping. No tone mapping is applied at all to the Input to Timeline Color Space conversion, leaving a plain 1:1 mapping to the Timeline Color Space.
- Clip: Hard clips all out-of-bounds values.
- Simple: Relies on a plain curve to carry out this conversion, squeezing or stretching the

highlights and/or shadows belonging to the timeline dynamic range so they sit better inside the output dynamic range. Bear in mind the “Simple” choice spans roughly 5500 nits down to 100 nits, which means that converting an HDR source carrying beyond 5500 nits toward an SDR destination can still leave a degree of clipping in the highlights past 5500 nits.

- Luminance Mapping: Behaves like DaVinci, yet proves more precise once the Input Color Space of every piece of your media sits within one standards-based color space, for example Rec. 709 or Rec. 2020.
- DaVinci: This choice tone maps the transform with a gentle luminance roll-off through the shadows and highlights, plus managed desaturation of image values in the very brightest and darkest regions of the picture. The setting is especially handy for wide-gamut camera media and makes a solid choice when blending media originating from different cameras.
- Saturation Preserving: This choice carries a gentle luminance roll-off through the shadows and highlights, yet accomplishes it without desaturating dark shadows and bright highlights, making it an effective pick for colorists who prefer to drive color more aggressively. Still, because over-saturation in a picture's highlights can appear unnatural, two parameters are surfaced to supply a measure of user-adjustable automated desaturation.

Sat. Rolloff Start: Lets you assign a threshold, expressed in nits (cd/m2), where saturation begins rolling off in tandem with highlight luminance. Beginning of the rolloff. Sat. Rolloff Limit: Lets you assign a threshold, expressed in nits (cd/m2), at which the picture becomes wholly desaturated. End of the rolloff. Max Input/Output Luminance Nudging the sliders lets you state the lowest and highest luminance of the input picture in nits. Working these two sliders in combination, you decide which value drawn from the Input Gamma maps over to which value of the Output Gamma. Average Input Luminance Applied to make up for sizable shifts in the viewer's degree of visual adaptation between seeing a bright picture on an HDR display and seeing that very picture on an SDR display. For the majority of “average” pictures this setting performs best between 0–10. That said, when you're converting extremely bright pictures (a snow scene at noon, say), a higher value will surface more image detail inside the highlights. Gamut Mapping Method Handles workflows where one color space must be transformed into another carrying a far bigger or far smaller gamut, by helping automate a stretch or squeeze of image saturation in a manner that yields a pleasing, naturalistic outcome without clipping. Picking Saturation Mapping lets you remap the saturation values of the picture. Doing so activates the Saturation Knee and Saturation Max. controls.

- The Saturation Knee slider establishes the picture level where saturation mapping kicks in. Beneath that level, nothing gets remapped. Every saturation value from that level upward gets remapped per the Saturation Max. slider. A value of 1.0 represents full saturation within the output color space currently chosen.
- The Saturation Max. slider establishes the fresh ceiling to which you intend to either lift or drop all saturation values sitting above the Saturation Knee setting. A value of 1.0 represents full saturation within the output color space currently chosen.
