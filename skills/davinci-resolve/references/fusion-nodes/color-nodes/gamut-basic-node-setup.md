### Basic Node Setup


Typically, you position a Gamut node right behind the MediaIn node in DaVinci Resolve, or behind a Loader node when you work in Fusion Studio. A second Gamut node generally sits at the tail of the node tree, just ahead of a MediaOut node in DaVinci Resolve or ahead of a Saver node in Fusion Studio.
