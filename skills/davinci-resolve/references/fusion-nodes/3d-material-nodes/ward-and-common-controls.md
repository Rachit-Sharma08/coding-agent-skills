### Transmittance

How light travels through a material is governed by Transmittance. Take a solid blue sphere: it throws a black shadow, whereas the same sphere made of translucent blue plastic would throw a far lighter blue shadow. A distinct Opacity option exists as well. Opacity sets just how see-through the actual surface appears once rendered. Fusion lets you dial opacity and transmittance independently. To anyone new to 3D software, that can seem a little odd at first. You can in fact have a surface that is wholly opaque yet still transmits 100% of the light landing on it, which in effect turns it into a luminous/emissive surface. Attenuation Attenuation governs how much color makes it through the object. To give an object transmissive shadows, dial the attenuation to (1, 1, 1), meaning 100% of the green, blue, and red light travels through the object. Dialing this color to RGB (1, 0, 0) means the material lets 100% of the incoming red through the surface while blocking the green and blue entirely. You can exploit this to fashion "stained glass"-style shadows. Alpha Detail With the Alpha Detail slider at 0, the object's Alpha channel is disregarded and the whole object casts a shadow. Push it to 1, and the Alpha channel decides which parts of the object cast a shadow.

Color Detail The Color Detail slider tints the light traveling through the surface using the diffuse color plus texture colors. Reach for this to cast a shadow carrying the color detail of the texture on the object. Pushing the slider up from 0 toward 1 feeds more diffuse color plus texture color into the shadow. Keep in mind that the object's Alpha and opacity are disregarded while color is being transmitted, so an object with a solid Alpha can still pass its color along to the shadow. Saturation The Saturation slider rules how saturated the color component handed to the shadow is. Drop this to 0.0 and you get monochrome shadows. Receives Lighting/Shadows Whether the scene's lighting and shadows touch the material is controlled by these checkboxes. Switch them off and the object stays fully lit and/or free of shadow. Two-Sided Lighting This basically turns the surface into a two-sided one by laying a second set of normals, pointed the opposite way, onto the back of the surface. It usually stays off to keep rendering fast, but you can switch it on for 2D surfaces or for objects that aren't fully sealed, so the back or interior faces show up too. Ordinarily, a 3D application shows only the front face of a surface and culls the back, so that if a camera circled a plane in a 3D application, the plane would vanish once it reached the backside. Making a plane two sided in a 3D application amounts to stacking another plane atop the first but spun 180 degrees, so its normals point the opposite way on the backside. So as you circle around the back, the second image plane comes into view, its normals turned the other direction. When you make a surface two sided, Fusion behaves precisely as those 3D applications do. The muddle over what two-sided lighting accomplishes stems from the fact that Fusion does not cull back-facing polygons by default. Circle a one-sided plane in Fusion and you still see it from the backside (though what you see is the frontside carried straight through to the back as if it were transparent). Make the plane two sided and you have effectively added a second set of normals onto the back of the plane. NOTE: Things can get fairly confusing once the surface goes transparent, because the same rules keep applying and hand you a counterintuitive outcome. View a transparent two-sided surface from the front while it is lit from behind, and it appears unlit. Material ID This slider assigns the numeric identifier given to this material. The value is rendered into the MatID auxiliary channel whenever the matching option is switched on in the renderer.

### The Common Controls

A set of identical controls in the Inspector is shared by nodes that work with 3D geometry. The controls covered here are the ones common to the 3D Material nodes.

### Settings Tab

### Common Settings 3D controls

Common Settings tab appears on the majority of Fusion's tools The controls listed next pertain specifically to 3D nodes Hide Incoming Connections Turning on this checkbox can suppress the connection lines coming from upstream nodes, leaving a node tree that looks tidier and reads more easily. With it enabled, a field appears for each input on a node. Drag a connected node out of the node tree into that field and the incoming connection line stays hidden, provided the node isn't selected in the node tree. Select the node in the node tree and the line comes back. Comment Tab A single text control lives in the Comment tab, where you jot comments and notes onto the tool. Add a note to a tool and a small red dot icon shows up beside the setting's tab icon, with a text bubble appearing on the node. To read the note in the Node Editor, rest the mouse pointer over the node for a moment. If you need it, the Comments tab's contents can be animated across time. Scripting Tab Every tool in Fusion carries the Scripting tab. Inside it are several edit boxes for adding scripts that run while the tool renders. To learn more about what this tab holds, refer to the scripting documentation.
