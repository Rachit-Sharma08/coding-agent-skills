### Inputs

A pair of inputs take 3D scenes as their sources. The orange scene input is mandatory, whereas the green Target input is optional. SceneInput: The mandatory orange scene input takes a 3D scene's output. That scene ought to hold the object or point in 3D space you mean to convert into 2D coordinates. Target: The optional green target input takes a 3D scene's output. Supply one and the scene's transform center fixes the Locator's position, after which the Locator's transformation controls act as offsets from that position.

### Basic Node Setup

Whatever scene you feed the Locator’s input has to include the camera that the coordinates get projected through. The recommended practice, then, is to position the Locator downstream of the Merge that brings the camera into the scene. Wire an object into the Locator node’s target input and the Locator parks itself at that object’s center, while the Transformation tab’s translation XYZ sliders operate in the object’s local coordinate space rather than global scene space. That comes in handy for following an object’s position even as extra transformations get applied further down the chain.

### Locator 3D controls

### Controls Tab

Nearly all of the locator 3D's controls are cosmetic, governing how the locator looks and whether it appears in the final output. The Camera Settings, by contrast, are essential to landing the results you're after. Size The Size slider sets how large the Locator’s onscreen crosshair is. Color A plain Color control sets the hue of the Locator’s onscreen crosshair. Matte Turning on the Is Matte option lays a special texture over this object, which makes it not just invisible to the camera but also hides anything sitting directly behind it from the camera. This option supersedes every texture.

- Is Matte: Once active, objects whose pixels lie behind the matte object’s pixels in Z stop being rendered.
- Opaque Alpha: Pins the matte object's Alpha value at 1. The checkbox shows only while the Is Matte option is on.
- Infinite Z: Drives the Z-channel value to infinity. The checkbox shows only while the Is Matte option is on.

Sub ID The Sub ID slider lets you single out one subelement of certain geometry, like a particular character generated by a Text 3D node or a specific copy spawned by a Duplicate 3D node.

Make Renderable Sets whether the OpenGL renderer draws the Locator as a visible object. The software renderer can't currently draw lines, so it disregards this option. Unseen by Camera This checkbox surfaces once the Make Renderable option is on. Tick the Unseen by Camera checkbox and the Locator stays visible in the viewers, though the Renderer 3D node keeps it out of the rendered output image. Camera Use this drop-down to pick which Camera in the scene defines the screen space behind the 3D-to-2D coordinate transformation. Use Frame Format Settings Tick this checkbox to bypass the width, height, and pixel aspect controls and compel them to adopt the values set in the composition’s Frame Format preferences. Width, Height, and Pixel Aspect For the Locator to compute a correct 2D transformation, it needs the image's dimensions and aspect. Set these controls to match the dimensions of the image produced by a renderer tied to the camera named above. Right-click these controls to bring up a contextual menu listing the frame formats defined in the composition’s preferences.

### Merge 3D [3Mg]

### The Merge 3D node

### Merge 3D Introduction

Within Fusion, the Merge 3D node is the chief node for bringing distinct 3D elements together into one shared 3D environment. Take a scene built from an image plane, a camera, and a light: the camera can't see the image plane and the light won't touch it until all three are gathered into the same environment via the Merge 3D node. The Merge carries the usual transformation controls present on most nodes in Fusion’s 3D suite. What sets it apart is that altering the Merge's translation, rotation, or scale ripples through to every object wired into the Merge. That very behavior underpins all parenting inside Fusion’s 3D environment.

### Inputs

At first the Merge node shows just two inputs, but each time you connect one a fresh input pops up on the node, guaranteeing one is always open for adding another element to the scene. SceneInput[#]: You use these multicolored inputs to attach image planes, 3D cameras, lights, complete 3D scenes, and other Merge 3D nodes too. The node accepts an unlimited number of inputs, sprouting more on the fly as required so that at least one input remains free for connection.

### Basic Node Setup

A Merge 3D sits at the center of any 3D composite, with every element of a 3D scene feeding into it. You can chain several Merge 3D nodes together to manage lighting or simply to keep things tidier. The final Merge 3D in such a chain has to attach to a Renderer 3D before it can come out as a 2D image.

### Merge 3D controls

### Controls Tab

The Controls tab serves a single purpose: passing through whatever lights are wired to the Merge 3D node. Pass Through Lights Tick the Pass Through Lights checkbox and lights travel through the Merge into its output to influence downstream elements. By default, lights aren't forwarded downstream to reach the rest of the scene. This is commonly used to keep projections from landing on geometry brought in later in the scene.

### Override 3D [3Ov]

### The Override 3D node

### Override 3D Node Introduction

With the Override node you can alter object-specific options for every object in a 3D scene all at once. It helps, say, when you want each object in the input scene to render as a wireframe. On top of that, for 3D particle systems and the Text 3D node, this node is your only route to setting the wireframe, visibility, lighting, matte, and ID options.

### Inputs

SceneInput: The orange Scene input takes the output from a Merge 3D node or from any node that builds a 3D scene.
