### Settings Tab

### Common Settings 3D controls

The Common Settings tab turns up on most tools in Fusion. The controls below are the settings particular to 3D nodes. Hide Incoming Connections Ticking this checkbox can conceal the connection lines from upstream nodes, giving a node tree a tidier, more readable look. With it on, an empty field for each of the node’s inputs shows in the Inspector. Drag a connected node out of the node tree and into the field to hide that incoming connection line, provided the node stays unselected in the node tree. Select the node in the node tree and the line comes back. Comment Tab The Comment tab holds a single text control for adding comments and notes to the tool. Once a note is on a tool, a small red dot icon appears beside the setting tab’s icon and a text bubble shows on the node. To read the note within the Node Editor, hover the pointer over the node briefly. The contents of the Comments tab can be animated over time when needed. Scripting Tab Every tool in Fusion carries the Scripting tab. It holds several edit boxes for adding scripts that run as the tool renders. For fuller detail on what this tab contains, see the scripting documentation.
