### The Common Film settings inspector

### Settings Tab

Every tool in the Film category carries the Inspector's Settings tab, and you will even meet these Settings controls on third-party Film-type plugin tools. They behave identically from one tool to the next, though a handful of tools add one or two unique options, which are documented here as well. Blend Turn to the Blend control to mix the tool's untouched image input against its final, altered output image. At a blend value of 0.0, what leaves the tool matches what entered it, and as a rule the tool then bypasses processing altogether, passing the input straight through to the output. Process When Blend Is 0.0 With this on, the tool still processes even though the input value reads zero. That comes in handy when a script ties this node's processing to firing off another task while the node's own value sits at 0.0.

Red/Green/Blue/Alpha Channel Selector This group of four buttons confines what the tool does to the color channels you pick. Typically this filter kicks in once the tool has finished processing. Take a Blur tool with its red button switched off: the blur runs across the whole image first, after which the red channel taken from the original input is laid back over the result's red channel. A few tools break this pattern, where turning off a channel makes the tool bypass processing that channel completely. Such tools usually carry their own matching set of RGBA buttons on the tool's Controls tab. Here the buttons found on the Settings tab and on the Controls tab match one another. Apply Mask Inverted Turning on the Apply Mask Inverted option flips the entire mask channel belonging to the tool. That mask channel is the merged product of every mask either fed into or produced within a node. Multiply by Mask Choosing this option multiplies the RGB values of the masked image by the values held in the mask channel. As a result, every pixel left out of the mask (that is, set to 0) ends up black/transparent. Use Object/Use Material (Checkboxes) Certain 3D software is able to render to file formats carrying extra channels. The EXR file format in particular handles Object and Material ID channels, and either can serve as a mask for the effect. Whether those channels get used, when they exist, is governed by these checkboxes. Which exact Material ID or Object ID is targeted gets picked with the controls that follow. Correct Edges You will only see this checkbox once the Use Object or Use Material checkboxes are turned on. It switches between methods for handling the overlapping edges of objects in an image that holds several objects. With it on, the Coverage and Background Color channels help isolate and refine the effect along the object's edge. Leave the option off (or work without Coverage or Background Color channels), and the mask's edge can show aliasing. For further reading on Coverage and Background Color channels, consult either Chapter 78, “Understanding Image Channels,” found within the DaVinci Resolve Reference Manual, or, alternatively, Chapter 18 over in the Fusion Reference Manual. Object ID/Material ID (Sliders) These sliders let you pick which ID builds a mask out of an image's object or material channels. Operate the Sample button just as you would the Color Picker: to pull IDs straight from the image shown in the view. Whatever image or sequence you use has to have come out of a 3D software package that included those channels.

Clipping Mode With this option you set how edges get treated during domain of definition rendering. It carries the most weight for nodes such as Blur, which can need samples drawn from regions of the image beyond the current domain.

- Frame: Frame is the option chosen by default; it makes the node's domain of definition span the image's full frame, in effect disregarding the current domain of definition. Where the upstream DoD comes up shorter than the frame, whatever frame area is left over reads as black/transparent.
- Domain: Picking Domain has the node honor the upstream domain of definition as its effect is applied. That can produce unwanted clipping wherever the node leans on a large filter.
- None: Picking None skips any clipping of the source image whatsoever. So any data the node needs to compute its effect that would ordinarily fall beyond the upstream DoD reads as black/transparent.

Use GPU There are three choices on the Use GPU menu. Choosing Disable shuts off hardware-accelerated rendering through your computer's graphics card. Enabled puts the hardware to work. Auto leans on a capable GPU when one exists and drops back to software rendering whenever no capable GPU is around Comments You use the Comments field to attach notes to a tool. Click the blank field and enter your text. Once a note is attached to a tool, a tiny red square shows in the node's lower-left corner while the full tile is shown, or a tiny text bubble icon shows on the right while nodes sit collapsed. To view the note within the Node Editor, rest the mouse pointer on the node so the tooltip appears. Scripts Each tool in Fusion offers three Scripting fields from the Settings tab. Every one holds an edit box where you can drop in scripts that run while the tool renders. For deeper detail on scripting nodes, turn to the Fusion scripting documentation.
