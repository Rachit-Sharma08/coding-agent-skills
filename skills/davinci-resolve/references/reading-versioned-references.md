# Reading versioned Resolve references

Identify the Resolve version, page, selected media or timeline, and intended operation before applying a procedure.
The 20.3 Reference Manual and the separate 21 New Features Guide describe different releases. Retain beta, Studio, hardware, edition, platform, and format conditions; a 21 feature does not establish availability in 20.3.
Read the owning control, preceding setup, and following conditions. Timeline, source-clip, node, track, bus, and project controls have different scopes.
Preserve menu paths, control labels, shortcuts, numerical units, and the documented sequence. Check the stated output or observable result, including color-management and audio-routing conditions.
Rendering, media management, relinking, and project-library operations need the documented target, format, and recovery conditions.
Extracted diagram labels do not reconstruct connections. Use the linked official diagram when topology matters.
Reference reading does not establish native application behavior or current-release availability. Check the installed version when investigating a defect.
