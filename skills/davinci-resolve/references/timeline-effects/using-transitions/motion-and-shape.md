### Motion

Motion transitions draw on the frames’ movement to lend a sense of real physical momentum to the shift from the outgoing clip to the incoming one.

- Barn Door: Color decides the border’s shade, should one be present. Border, given in pixels, governs how wide that border runs; set it to 0 and none appears. Feather, once its checkbox is ticked, leans on the Border slider to set how softly the transition’s edge feathers. Motion Blur eases the transition’s frame-to-frame movement. Reverse, a checkbox, swaps the transition’s direction. Preset mode offers a pick from these presets:
- Barn Door Vertical
- Barn Door Horizontal
- Push: Color decides the border’s shade, should one be present. Border, given in pixels, governs how wide that border runs; set it to 0 and none appears. Feather, once its checkbox is ticked, leans on the Border slider to set how softly the transition’s edge feathers. Motion Blur eases the transition’s frame-to-frame movement. Preset mode offers a pick from these presets:
- Push Left
- Push Right
- Push Up
- Push Down
- Slide: Direction decides which clip does the sliding, the incoming one sliding in or the outgoing one sliding out. Color decides the border’s shade, should one be present. Border, given in pixels, governs how wide that border runs; set it to 0 and none appears. Feather, once its checkbox is ticked, leans on the Border slider to set how softly the transition’s edge feathers. Motion Blur eases the transition’s frame-to-frame movement. Preset mode offers a pick from these presets:
- Slide, Left-Right
- Slide, Right-Left
- Slide, Bottom-Up
- Slide, Top-Down
- Slide, Top-Left
- Slide, Bottom-Right
- Split: Color decides the border’s shade, should one be present. Border, given in pixels, governs how wide that border runs; set it to 0 and none appears. Feather, once its checkbox is ticked, leans on the Border slider to set how softly the transition’s edge feathers. Reverse, a checkbox, swaps the transition’s direction. Motion Blur eases the transition’s frame-to-frame movement.

### Shape

Shape transitions lean on geometric outlines to carve the move from the outgoing clip to the incoming one. Best results come when the chosen shape grows out of what the scenes themselves contain.

- Box: Color decides the border’s shade, should one be present. Border, given in pixels, governs how wide that border runs; set it to 0 and none appears. Feather, once its checkbox is ticked, leans on the Border slider to set how softly the transition’s edge feathers. Reverse, a checkbox, swaps the transition’s direction. Box mode hands you a pick among these options:
- Upper Left
- Upper Right
- Lower Left
- Lower Right
- Left Center
- Top Center
- Right Center
- Bottom Center
- Heart: Color decides the border’s shade, should one be present. Border, given in pixels, governs how wide that border runs; set it to 0 and none appears. Aspect Ratio lets the shape’s proportions be reshaped. Offset to Center marks, in on-screen X and Y coordinates, the point from which this circular wipe sets off. Rotation turns the shape to a new angle. Feather, once its checkbox is ticked, leans on the Border slider to set how softly the transition’s edge feathers. Reverse, a checkbox, swaps the transition’s direction.
- Star: Color decides the border’s shade, should one be present. Border, given in pixels, governs how wide that border runs; set it to 0 and none appears. Aspect Ratio lets the shape’s proportions be reshaped. Offset to Center marks, in on-screen X and Y coordinates, the point from which this circular wipe sets off. Rotation turns the shape to a new angle. Feather, once its checkbox is ticked, leans on the Border slider to set how softly the transition’s edge feathers.

Reverse, a checkbox, swaps the transition’s direction. Preset hands you a pick among these options:

- 4-Point Star
- 5-Point Star
- 6-Point Star
- Triangle Left: Color decides the border’s shade, should one be present. Border, given in pixels, governs how wide that border runs; set it to 0 and none appears. Feather, once its checkbox is ticked, leans on the Border slider to set how softly the transition’s edge feathers. Reverse, a checkbox, swaps the transition’s direction.
- Triangle Right: Color decides the border’s shade, should one be present. Border, given in pixels, governs how wide that border runs; set it to 0 and none appears. Feather, once its checkbox is ticked, leans on the Border slider to set how softly the transition’s edge feathers. Reverse, a checkbox, swaps the transition’s direction.
